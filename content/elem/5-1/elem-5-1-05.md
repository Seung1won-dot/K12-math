## 핵심 개념

> **한 줄 요약.** 분모가 다른 분수는 먼저 통분해서 조각 크기를 맞춘 뒤, 분자끼리 더하거나 뺀다.

4학년에서는 $\dfrac{2}{5} + \dfrac{1}{5}$처럼 **분모가 같은** 분수만 더하고 뺐다. 분모가 같으면 조각 크기가 같으므로 분자만 더하면 된다. 이 단원에서는 $\dfrac{1}{2} + \dfrac{1}{3}$처럼 **분모가 다른** 분수를 더하고 뺀다.

분모가 다르면 조각의 크기가 달라서 분자를 그냥 더할 수 없다. 그래서 먼저 **통분**해서 조각 크기를 맞춘 다음, 분모가 같은 분수의 덧셈·뺄셈으로 바꿔 계산한다. "통분 → 분자끼리 계산 → 약분·대분수 정리"가 이 단원의 전부다.

**대분수**가 섞인 계산은 두 가지 방법이 있다. 자연수 부분과 분수 부분을 따로 계산하는 방법, 또는 대분수를 가분수로 고쳐 한꺼번에 계산하는 방법이다. 뺄셈에서 분수 부분이 모자라면 자연수에서 $1$을 빌려 오는 **받아내림**이 필요하다.

**생활 속에서.** 요리법에 "우유 $\dfrac{1}{2}$컵과 물 $\dfrac{1}{3}$컵"이 있으면 그릇에 붓는 양은 모두 얼마일까? 계량컵 눈금이 $\dfrac{1}{6}$컵 단위라면 우유는 $3$칸, 물은 $2$칸으로 읽을 수 있어서 합이 $5$칸, $\dfrac{5}{6}$컵이다. 길이, 들이, 시간처럼 분수로 나타낸 양을 합치거나 남은 양을 구할 때마다 이 계산을 쓴다.

## 공식·정리

**기억할 방법**

1. 분모가 다르면 **두 분모의 최소공배수**로 통분한다. (두 분모의 곱으로 통분해도 되지만 약분할 일이 많아진다.)
2. 통분한 뒤 **분자끼리** 더하거나 뺀다. 분모는 그대로 둔다.
3. 결과가 가분수이면 대분수로 고치고, 약분할 수 있으면 기약분수로 만든다.

$$
\frac{1}{4} + \frac{5}{6} = \frac{3}{12} + \frac{10}{12} = \frac{13}{12} = 1\frac{1}{12}
$$

- 조건: 분모끼리 더하거나 빼지 **않는다.** 분모는 조각 크기이므로 통분한 뒤에도 그대로다.
- 조건: 뺄셈은 큰 수에서 작은 수를 빼는 경우만 다룬다. 결과가 $0$보다 작아지는 계산은 중학교에서 배운다.

**대분수의 뺄셈에서 받아내림**

분수 부분끼리 뺄 수 없을 때 자연수에서 $1$을 빌려 와 분수로 바꾼다. 빌린 $1$은 **분모와 같은 수를 분자로 하는 분수**($\dfrac{6}{6}$, $\dfrac{12}{12}$ 등)다.

$$
3\frac{1}{6} - 1\frac{5}{6} = 2\frac{7}{6} - 1\frac{5}{6} = 1\frac{2}{6} = 1\frac{1}{3}
$$

- 조건: 통분을 먼저 한 뒤에 받아내림을 판단한다. 통분 전의 분자 크기로 판단하면 틀린다.
- 검산: 뺄셈 결과에 뺀 수를 다시 더해 원래 수가 나오는지, 또는 분수를 소수로 어림해 확인한다.

## 대표 예제

**예제 1 (기본).** $\dfrac{1}{4} + \dfrac{5}{6}$을 계산하시오.

풀이 전략: 최소공배수로 통분 → 분자끼리 더하기 → 가분수는 대분수로.

1. $4$와 $6$의 최소공배수는 $12$다.
2. $\dfrac{1}{4} = \dfrac{3}{12}$, $\dfrac{5}{6} = \dfrac{10}{12}$.
3. 분자끼리 더하면 $\dfrac{13}{12}$.
4. 가분수이므로 $\dfrac{13}{12} = 1\dfrac{1}{12}$.

확인: $\dfrac{1}{4} = 0.25$, $\dfrac{5}{6}$은 약 $0.83$이므로 합은 약 $1.08$이고, $1\dfrac{1}{12}$도 약 $1.08$이다.

**예제 2 (표준).** $\dfrac{7}{8} - \dfrac{1}{6}$을 계산하시오.

풀이 전략: 최소공배수로 통분한 뒤 분자끼리 빼고, 약분되는지 본다.

1. $8$과 $6$의 최소공배수는 $24$다.
2. $\dfrac{7}{8} = \dfrac{21}{24}$, $\dfrac{1}{6} = \dfrac{4}{24}$.
3. $\dfrac{21}{24} - \dfrac{4}{24} = \dfrac{17}{24}$.
4. $17$과 $24$의 공약수는 $1$뿐이므로 기약분수다.

확인: $\dfrac{17}{24} + \dfrac{4}{24} = \dfrac{21}{24} = \dfrac{7}{8}$.

**예제 3 (표준).** $3\dfrac{1}{3} - 1\dfrac{5}{6}$을 계산하시오.

풀이 전략: 분수 부분을 먼저 통분하고, 분수 부분끼리 뺄 수 없으면 받아내림한다.

1. 통분: $3\dfrac{1}{3} = 3\dfrac{2}{6}$.
2. $\dfrac{2}{6}$에서 $\dfrac{5}{6}$을 뺄 수 없으므로 받아내림: $3\dfrac{2}{6} = 2\dfrac{8}{6}$.
3. 자연수끼리, 분수끼리: $2\dfrac{8}{6} - 1\dfrac{5}{6} = 1\dfrac{3}{6}$.
4. 약분: $1\dfrac{3}{6} = 1\dfrac{1}{2}$.

확인: 가분수로 바꿔 계산하면 $\dfrac{10}{3} - \dfrac{11}{6} = \dfrac{20}{6} - \dfrac{11}{6} = \dfrac{9}{6} = 1\dfrac{1}{2}$로 같다.

**예제 4 (응용).** 물통에 물이 $2\dfrac{1}{2}\,\text{L}$ 있었다. $\dfrac{3}{4}\,\text{L}$를 마시고 $1\dfrac{2}{5}\,\text{L}$를 더 부었다. 지금 물은 몇 L인가?

풀이 전략: 식 $2\dfrac{1}{2} - \dfrac{3}{4} + 1\dfrac{2}{5}$를 왼쪽부터 두 단계로 계산한다. 단계마다 통분한다.

1. $2\dfrac{1}{2} - \dfrac{3}{4} = 2\dfrac{2}{4} - \dfrac{3}{4}$. 분수 부분이 모자라므로 받아내림: $1\dfrac{6}{4} - \dfrac{3}{4} = 1\dfrac{3}{4}$.
2. $1\dfrac{3}{4} + 1\dfrac{2}{5}$에서 $4$와 $5$의 최소공배수는 $20$: $1\dfrac{15}{20} + 1\dfrac{8}{20} = 2\dfrac{23}{20}$.
3. $\dfrac{23}{20} = 1\dfrac{3}{20}$이므로 $2\dfrac{23}{20} = 3\dfrac{3}{20}$.

**예제 5 (심화).** 어떤 수에서 $\dfrac{2}{3}$을 빼야 할 것을 잘못하여 더했더니 $1\dfrac{5}{6}$이 되었다. 바르게 계산한 값을 구하시오.

풀이 전략: 잘못한 계산을 거꾸로 해서 어떤 수를 먼저 구하고, 그다음 바른 계산을 한다.

1. (어떤 수) $+ \dfrac{2}{3} = 1\dfrac{5}{6}$이므로 (어떤 수) $= 1\dfrac{5}{6} - \dfrac{2}{3} = 1\dfrac{5}{6} - \dfrac{4}{6} = 1\dfrac{1}{6}$.
2. 바르게 계산하면 $1\dfrac{1}{6} - \dfrac{2}{3} = \dfrac{7}{6} - \dfrac{4}{6} = \dfrac{3}{6} = \dfrac{1}{2}$.

확인: $1\dfrac{1}{6} + \dfrac{2}{3} = \dfrac{7}{6} + \dfrac{4}{6} = \dfrac{11}{6} = 1\dfrac{5}{6}$으로 문제의 조건과 맞다. 답은 $\dfrac{1}{2}$.

2. $\dfrac{5}{6} - \dfrac{3}{10}$을 계산하여 기약분수로 나타내시오.
3. $4\dfrac{1}{4} - 2\dfrac{2}{3}$을 계산하시오.

1. $3$과 $4$의 최소공배수 $12$로 통분: $\dfrac{8}{12} + \dfrac{9}{12} = \dfrac{17}{12} = 1\dfrac{5}{12}$.

## 자주 하는 실수와 오개념

**실수 1. 통분하지 않고 분모끼리, 분자끼리 더한다.**

- **왜 틀리는가:** $\dfrac{1}{2} + \dfrac{1}{3} = \dfrac{2}{5}$라고 쓴다. 분수를 "두 수가 위아래로 있는 것"으로만 보고, 분모가 조각 크기라는 뜻을 잊는다.
- **어떻게 바로잡는가:** $\dfrac{2}{5}$는 $\dfrac{1}{2}$보다 작으므로, $\dfrac{1}{2}$에 무언가를 더했는데 작아질 수는 없다고 어림으로 확인시킨다. 막대 그림으로 칸 크기를 맞춘 뒤 세어 $\dfrac{5}{6}$이 나오는 것을 보인다.

**실수 2. 통분하면서 분모만 바꾸고 분자는 그대로 둔다.**

- **왜 틀리는가:** $\dfrac{1}{4} + \dfrac{5}{6}$에서 분모를 $12$로 바꾼 뒤 $\dfrac{1}{12} + \dfrac{5}{12} = \dfrac{6}{12}$으로 계산한다. 분모에 곱한 수를 분자에도 곱해야 크기가 유지된다.
- **어떻게 바로잡는가:** 통분한 분수가 원래 분수와 크기가 같은지 약분해서 되돌아가는지 확인한다. 앞 단원 약분과 통분의 그림(조각을 잘게 쪼개면 색칠한 조각 수도 늘어난다)을 다시 본다.

**실수 3. 받아내림할 때 $1$을 $\dfrac{10}{10}$으로 바꾼다.**

- **왜 틀리는가:** 자연수 뺄셈의 받아내림이 "$10$을 빌려 온다"였기 때문에 분수에서도 $10$을 쓴다. $3\dfrac{1}{6}$을 $2\dfrac{11}{6}$으로 잘못 쓴다.
- **어떻게 바로잡는가:** $1$은 분모가 $6$이면 $\dfrac{6}{6}$, 분모가 $12$이면 $\dfrac{12}{12}$라는 것을 막대 그림으로 보인다. 받아내림한 분수 부분은 "원래 분자 $+$ 분모"가 되어야 한다($1 + 6 = 7$).

**실수 4. 뺄셈에서 분수 부분이 모자라면 작은 수에서 큰 수를 뺀다.**

- **왜 틀리는가:** $3\dfrac{1}{6} - 1\dfrac{5}{6}$에서 $\dfrac{1}{6}$에서 $\dfrac{5}{6}$을 뺄 수 없으니 거꾸로 $\dfrac{5}{6} - \dfrac{1}{6}$을 계산해 $2\dfrac{4}{6}$이라고 쓴다. 뺄셈은 순서를 바꾸면 값이 달라진다.
- **어떻게 바로잡는가:** 답에 뺀 수를 다시 더해 원래 수가 나오는지 검산하게 한다($2\dfrac{4}{6} + 1\dfrac{5}{6} = 4\dfrac{3}{6}$으로 $3\dfrac{1}{6}$이 아니다). 분수 부분이 모자라면 반드시 받아내림을 한다고 정한다.

**실수 5. 계산 결과를 가분수나 약분되는 분수 그대로 둔다.**

- **왜 틀리는가:** $1\dfrac{3}{6}$이나 $2\dfrac{23}{20}$에서 멈춘다. 계산은 맞았지만 분수 부분이 $1$보다 크거나 약분이 남아 있어 정리가 끝나지 않았다.
- **어떻게 바로잡는가:** 답을 쓰기 전 마지막 점검으로 "분수 부분이 $1$보다 작은가?", "분모와 분자에 공약수가 남아 있지 않은가?" 두 가지를 확인한다.

## 앞뒤 학년 연계

4학년 「분수의 덧셈과 뺄셈」(분모가 같은 경우)과 바로 앞 단원 「약분과 통분」이 합쳐진 단원이다. 2학기 「분수의 곱셈」에서는 통분이 필요 없다는 점이 덧셈·뺄셈과 가장 다른 점이고, 중학교에서 분수 계수가 있는 식을 정리할 때도 이 통분 과정을 그대로 쓴다.
