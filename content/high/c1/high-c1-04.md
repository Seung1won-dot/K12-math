## 핵심 개념

**복소수 범위의 이차방정식.** 중학교에서는 $b^2 - 4ac < 0$이면 "근이 없다"고 했다. 이제 수의 범위를 복소수까지 넓혔으므로 이런 경우에도 근의 공식으로 근을 구할 수 있다. 실수인 근을 **실근**, 허수인 근을 **허근**이라고 한다. 계수가 복소수일 수도 있지만, 이 단원에서는 특별한 말이 없으면 계수가 실수인 이차방정식 $ax^2 + bx + c = 0$ ($a \ne 0$)을 다룬다.

**판별식.** 근의 공식 $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$에서 근호 안의 $b^2 - 4ac$의 부호만 보면 근이 실근인지 허근인지 판별할 수 있다. 그래서 이 식을 **판별식**이라 하고 $D$로 쓴다. 판별식은 방정식을 직접 풀지 않고도 근의 종류를 알려 준다.

**근과 계수의 관계.** 두 근 $\alpha,\,\beta$의 합과 곱은 근을 직접 구하지 않아도 계수 $a,\,b,\,c$만으로 계산된다. 근이 복잡한 무리수나 허수일 때 특히 유용하다. 거꾸로 두 수의 합과 곱을 알면 그 두 수를 근으로 하는 이차방정식을 바로 만들 수 있다.

**켤레근.** 계수가 모두 실수인 이차방정식이 허근 $p + qi$를 가지면, 다른 한 근은 반드시 그 켤레복소수 $p - qi$이다. 비슷하게 계수가 모두 유리수이면 $p + q\sqrt{m}$이 근일 때 $p - q\sqrt{m}$도 근이다(단, $\sqrt{m}$은 무리수).

## 공식·정리

**판별식** ($a,\,b,\,c$는 실수, $a \ne 0$): $D = b^2 - 4ac$

- $D > 0$ $\iff$ 서로 다른 두 실근
- $D = 0$ $\iff$ 중근(서로 같은 두 실근)
- $D < 0$ $\iff$ 서로 다른 두 허근
- **실근을 가질 조건**은 $D \ge 0$ (중근도 실근이다)
- $b = 2b'$이면 $\dfrac{D}{4} = b'^2 - ac$를 써도 부호 판단은 같다.

**근과 계수의 관계**: $ax^2 + bx + c = 0$ ($a \ne 0$)의 두 근을 $\alpha,\,\beta$라 하면

$$
\alpha + \beta = -\frac{b}{a}, \qquad \alpha\beta = \frac{c}{a}
$$

이 관계는 근이 실근이든 허근이든 항상 성립한다.

**자주 쓰는 변형**

- $\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$
- $(\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta$
- $\dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta}$ $\quad(\alpha\beta \ne 0)$
- $\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)$

**두 수를 근으로 하는 이차방정식**: 두 수 $\alpha,\,\beta$를 근으로 하고 $x^2$의 계수가 $1$인 이차방정식은

$$
x^2 - (\alpha + \beta)x + \alpha\beta = 0
$$

**이차식의 인수분해**: $ax^2 + bx + c = 0$의 두 근이 $\alpha,\,\beta$이면 복소수 범위에서 $ax^2 + bx + c = a(x - \alpha)(x - \beta)$.

**켤레근**: 계수가 실수인 이차방정식의 한 근이 $p + qi$ ($p,\,q$ 실수, $q \ne 0$)이면 다른 한 근은 $p - qi$.

## 왜 성립하는가

**판별식의 의미.** 근의 공식에서 두 근은 $\dfrac{-b + \sqrt{D}}{2a}$, $\dfrac{-b - \sqrt{D}}{2a}$이다. $D > 0$이면 $\sqrt{D}$는 $0$이 아닌 실수라 두 근이 서로 다른 실수다. $D = 0$이면 $\pm\sqrt{D}$가 모두 $0$이라 두 근이 $-\dfrac{b}{2a}$로 같다. $D < 0$이면 $\sqrt{D} = \sqrt{-D}\,i$가 허수라 두 근이 서로 다른 허수다.

**근과 계수의 관계 유도.** 근의 공식의 두 근을 그대로 더하고 곱한다.

$$
\begin{aligned}
\alpha + \beta &= \frac{-b + \sqrt{D}}{2a} + \frac{-b - \sqrt{D}}{2a} = \frac{-2b}{2a} = -\frac{b}{a} \\
\alpha\beta &= \frac{(-b + \sqrt{D})(-b - \sqrt{D})}{4a^2} = \frac{b^2 - D}{4a^2} = \frac{b^2 - (b^2 - 4ac)}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}
\end{aligned}
$$

곱에서 $(\sqrt{D})^2 = D$는 $D < 0$이어도 성립한다($\sqrt{D} = \sqrt{-D}\,i$이므로 제곱하면 $-(-D) = D$). 그래서 허근일 때도 관계가 그대로 맞다.

**다른 유도(항등식).** 두 근이 $\alpha,\,\beta$이면 $ax^2 + bx + c = a(x - \alpha)(x - \beta) = ax^2 - a(\alpha + \beta)x + a\alpha\beta$가 $x$에 대한 항등식이다. 계수를 비교하면 $b = -a(\alpha + \beta)$, $c = a\alpha\beta$이므로 같은 결과를 얻는다. 같은 식에서 $a = 1$로 두면 두 수를 근으로 하는 방정식 $x^2 - (\alpha + \beta)x + \alpha\beta = 0$이 나온다.

**켤레근 정리.** $\alpha$가 근이면 $a\alpha^2 + b\alpha + c = 0$이다. 양변의 켤레복소수를 취하고 켤레복소수의 성질($\overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$, $\overline{z_1 z_2} = \overline{z_1}\;\overline{z_2}$)을 쓰면 $\overline{a}\,\overline{\alpha}^2 + \overline{b}\,\overline{\alpha} + \overline{c} = 0$이다. 계수가 실수이므로 $\overline{a} = a$, $\overline{b} = b$, $\overline{c} = c$이고, 따라서 $a\overline{\alpha}^2 + b\overline{\alpha} + c = 0$, 즉 $\overline{\alpha}$도 근이다. 계수가 실수라는 조건이 이 마지막 단계에서 꼭 필요하다.

## 대표 예제

**예제 1 (교과서 수준).** (1) 이차방정식 $x^2 + 2x + 5 = 0$을 푸시오. (2) 이차방정식 $x^2 - 2x + k = 0$이 서로 다른 두 실근, 중근, 서로 다른 두 허근을 가질 때 실수 $k$의 값 또는 범위를 각각 구하시오.

(1) $b' = 1$이므로 $x = -1 \pm \sqrt{1 - 5} = -1 \pm \sqrt{-4} = -1 \pm 2i$.

확인: $(-1 + 2i)^2 = 1 - 4i - 4 = -3 - 4i$이고, $2(-1 + 2i) = -2 + 4i$이므로 $(-3 - 4i) + (-2 + 4i) + 5 = 0$.

(2) $\dfrac{D}{4} = (-1)^2 - k = 1 - k$. 서로 다른 두 실근은 $1 - k > 0$에서 $k < 1$, 중근은 $k = 1$, 서로 다른 두 허근은 $k > 1$.

확인: $k = 1$이면 $x^2 - 2x + 1 = (x - 1)^2 = 0$으로 실제로 중근 $x = 1$이다.

**예제 2 (교과서 수준).** 이차방정식 $x^2 - 3x + 5 = 0$의 두 근을 $\alpha,\,\beta$라 할 때 다음을 구하시오. (1) $\alpha^2 + \beta^2$ (2) $\dfrac{1}{\alpha} + \dfrac{1}{\beta}$ (3) $\alpha + 1$, $\beta + 1$을 두 근으로 하고 $x^2$의 계수가 $1$인 이차방정식

근과 계수의 관계에서 $\alpha + \beta = 3$, $\alpha\beta = 5$.

(1) $\alpha^2 + \beta^2 = 3^2 - 2 \times 5 = -1$. 두 근이 허근이라 제곱의 합이 음수가 될 수 있다.

(2) $\dfrac{\alpha + \beta}{\alpha\beta} = \dfrac{3}{5}$.

(3) 합은 $(\alpha + 1) + (\beta + 1) = 5$, 곱은 $\alpha\beta + (\alpha + \beta) + 1 = 5 + 3 + 1 = 9$. 따라서 $x^2 - 5x + 9 = 0$.

확인: 실제 근은 $\alpha,\,\beta = \dfrac{3 \pm \sqrt{11}\,i}{2}$이다. $\alpha^2 = \dfrac{9 - 11 + 6\sqrt{11}\,i}{4} = \dfrac{-2 + 6\sqrt{11}\,i}{4}$이고 $\beta^2$은 허수부분의 부호만 반대이므로 $\alpha^2 + \beta^2 = \dfrac{-4}{4} = -1$로 (1)과 같다.

**예제 3 (심화).** (1) 실수 $a,\,b$에 대하여 이차방정식 $x^2 + ax + b = 0$의 한 근이 $1 + 2i$일 때 $a,\,b$의 값을 구하시오. (2) $x$에 대한 이차방정식 $x^2 - 2(k - 1)x + k^2 - 3 = 0$이 실근을 갖도록 하는 실수 $k$의 값의 범위를 구하시오.

(1) 계수가 실수이므로 다른 한 근은 $1 - 2i$이다. 두 근의 합 $2 = -a$에서 $a = -2$, 곱 $(1 + 2i)(1 - 2i) = 1 + 4 = 5 = b$.

다른 풀이: $x = 1 + 2i$를 대입하면 $(1 + 2i)^2 + a(1 + 2i) + b = (-3 + a + b) + (4 + 2a)i = 0$. $a,\,b$가 실수이므로 $-3 + a + b = 0$, $4 + 2a = 0$에서 $a = -2$, $b = 5$로 같다.

(2) 실근을 가지려면 중근도 포함해 $\dfrac{D}{4} \ge 0$이어야 한다.

$$
\frac{D}{4} = (k - 1)^2 - (k^2 - 3) = k^2 - 2k + 1 - k^2 + 3 = -2k + 4 \ge 0
$$

따라서 $k \le 2$. 확인: $k = 2$이면 방정식은 $x^2 - 2x + 1 = 0$으로 중근 $x = 1$(실근)을 가지고, $k = 3$이면 $x^2 - 4x + 6 = 0$에서 $\dfrac{D}{4} = 4 - 6 < 0$으로 허근이다.

## 자주 하는 실수와 오개념

**실수 1. "실근을 가진다"를 $D > 0$으로 푼다.**
왜 틀리는가: 중근도 실근이다. 예제 3 (2)에서 $D > 0$으로 풀면 $k < 2$가 되어 $k = 2$가 빠진다. 반대로 "서로 다른 두 실근"일 때 $D \ge 0$으로 쓰면 중근인 경우가 잘못 들어간다.
어떻게 바로잡는가: 문장을 그대로 부등호로 옮긴다. "실근" $\to D \ge 0$, "서로 다른 두 실근" $\to D > 0$, "중근" $\to D = 0$, "허근" $\to D < 0$. 답의 경계값을 넣어 확인한다.

**실수 2. 두 근의 합을 $\dfrac{b}{a}$로 쓴다.**
왜 틀리는가: $\alpha + \beta = -\dfrac{b}{a}$인데 부호를 빠뜨리는 실수가 가장 흔하다. $x^2 - 3x + 5 = 0$에서 합을 $-3$이라 하면 이후 계산이 모두 틀린다.
어떻게 바로잡는가: "합은 부호를 바꾸고, 곱은 그대로"라고 기억한다. 헷갈리면 $(x - 2)(x - 3) = x^2 - 5x + 6$처럼 근을 아는 식으로 합 $5 = -(-5)$를 확인한다. 두 근으로 방정식을 만들 때도 $x^2 - (\text{합})x + (\text{곱}) = 0$에서 $x$의 계수 앞 부호가 $-$임을 확인한다.

**실수 3. 계수가 실수가 아닌데 켤레근이나 판별식을 쓴다.**
왜 틀리는가: 켤레근 정리와 판별식에 의한 근의 판별은 계수가 실수일 때만 성립한다. 예를 들어 $x^2 - (1 + i)x + i = (x - 1)(x - i) = 0$의 근은 $1$과 $i$로, $i$의 켤레 $-i$는 근이 아니다.
어떻게 바로잡는가: 켤레근이나 $D$를 쓰기 전에 문제에 "계수가 실수", "실수 $a,\,b$"라는 조건이 있는지 확인한다. 계수가 무리수 켤레근을 쓸 때는 "계수가 유리수"라는 조건이 필요하다.

**실수 4. "이차방정식"의 조건 $a \ne 0$을 빠뜨린다.**
왜 틀리는가: $(k - 1)x^2 + 2x + 1 = 0$이 "이차방정식"이라고 했는데 판별식만 풀면 $k = 1$이 답에 섞일 수 있다. $k = 1$이면 일차방정식이 되어 판별식을 쓸 수 없다.
어떻게 바로잡는가: 이차항 계수에 문자가 있으면 먼저 "이차항 계수 $\ne 0$"을 적어 두고, 판별식으로 구한 범위와 함께 만족시키는 값만 답으로 쓴다. 문제가 "$x$에 대한 방정식"이라고만 하면 일차인 경우도 따로 따져야 한다.

## 앞뒤 학년 연계

중학교 3학년에서 배운 근의 공식과 앞 단원의 복소수가 이 단원의 도구다. 다음 단원에서는 이차방정식의 판별식이 이차함수의 그래프와 $x$축의 위치 관계(두 점에서 만남, 접함, 만나지 않음)와 같은 이야기라는 것을 배우고, 이후 삼차·사차방정식에서도 근과 계수의 관계와 켤레근 성질이 확장되어 쓰인다.
