## 핵심 개념

**삼차방정식과 사차방정식.** $f(x)$가 삼차식, 사차식일 때 $f(x) = 0$을 각각 삼차방정식, 사차방정식이라 한다. 고등학교에서는 이런 방정식을 **인수분해해서 일차식과 이차식의 곱으로 바꾼 뒤** 각 인수를 $0$으로 놓아 푼다. 복소수 범위에서 생각하면 삼차방정식은 중근을 포함해 근이 $3$개, 사차방정식은 $4$개다.

**인수분해하는 세 가지 방법.** 첫째, 인수정리: $f(\alpha) = 0$인 $\alpha$를 찾으면 $x - \alpha$가 인수이고, 조립제법으로 나머지 인수를 구한다. 둘째, 치환: $x^4 + ax^2 + b$처럼 $x^2$만 있는 식(복이차식)은 $x^2 = X$로 놓으면 $X$에 대한 이차식이 된다. 셋째, 그래도 안 되면 $A^2 - B^2$ 꼴을 만든다. 예를 들어 $x^4 + x^2 + 1 = (x^2+1)^2 - x^2$으로 바꾸어 두 이차식의 곱으로 나눈다.

**방정식 $x^3 = 1$의 허근 $\omega$.** $x^3 - 1 = (x-1)(x^2+x+1) = 0$이므로 근은 $1$과 $x^2 + x + 1 = 0$의 두 허근이다. 이 허근 중 하나를 $\omega$(오메가)라 부르는데, $\omega^3 = 1$이라는 성질 덕분에 $\omega$의 높은 거듭제곱을 간단하게 계산할 수 있다.

**연립이차방정식.** 미지수가 $2$개이고 차수가 가장 높은 식이 이차인 연립방정식이다. 일차식이 하나 있으면 그것을 한 문자에 대해 풀어 이차식에 대입한다. 두 식이 모두 이차식이면, 인수분해되는 식을 찾아 일차식 두 개로 쪼갠 뒤 각각을 다른 식과 연립한다.

## 공식·정리

**인수정리** (다항식 $f(x)$, 수 $\alpha$에 대하여)
$$
f(\alpha) = 0 \iff f(x) \text{는 } x - \alpha \text{로 나누어떨어진다}
$$

- 계수가 모두 정수인 $f(x)$에서 $f(\alpha) = 0$인 정수 $\alpha$를 찾을 때는 $\pm\dfrac{(\text{상수항의 약수})}{(\text{최고차항 계수의 약수})}$를 차례로 대입한다. 최고차항 계수가 $1$이면 상수항의 약수만 보면 된다.

**복이차방정식** $x^4 + ax^2 + b = 0$: $x^2 = X$로 치환하여 $X^2 + aX + b = 0$을 풀고, 각 $X$에 대해 $x^2 = X$를 다시 푼다. $X < 0$이면 $x = \pm\sqrt{-X}\,i$로 허근이 된다.

**$x^3 = 1$의 한 허근 $\omega$의 성질** ($\bar{\omega}$는 $\omega$의 켤레복소수)
$$
\omega^3 = 1, \qquad \omega^2 + \omega + 1 = 0, \qquad \omega + \bar{\omega} = -1, \qquad \omega\bar{\omega} = 1, \qquad \bar{\omega} = \omega^2 = \frac{1}{\omega}
$$

- 이 성질은 $x^2 + x + 1 = 0$의 근에만 해당한다. $x^3 = -1$의 허근(즉 $x^2 - x + 1 = 0$의 근)은 $\omega^3 = -1$, $\omega^2 - \omega + 1 = 0$으로 부호가 다르다.

**연립이차방정식**: (일차식, 이차식) 꼴은 대입법, (이차식, 이차식) 꼴은 인수분해되는 식을 일차식 두 개로 나누어 각각 연립한다. 해는 반드시 $(x,\,y)$ 순서쌍으로 짝지어 쓴다.

## 왜 성립하는가

**인수정리.** $f(x)$를 일차식 $x - \alpha$로 나누면 나머지는 상수이므로 $f(x) = (x - \alpha)Q(x) + R$로 쓸 수 있다. 양변에 $x = \alpha$를 넣으면 $f(\alpha) = 0 \cdot Q(\alpha) + R = R$이다(나머지정리). 그러므로 $f(\alpha) = 0$이면 $R = 0$이 되어 $f(x) = (x-\alpha)Q(x)$, 즉 $x - \alpha$가 인수다. 거꾸로 $x - \alpha$가 인수이면 $x = \alpha$를 넣었을 때 $0$이 된다.

**정수근 후보가 상수항의 약수인 이유.** 최고차항 계수가 $1$인 정수 계수 삼차식 $x^3 + px^2 + qx + r$에서 정수 $\alpha$가 근이면 $\alpha^3 + p\alpha^2 + q\alpha = -r$, 즉 $\alpha(\alpha^2 + p\alpha + q) = -r$이다. 괄호 안이 정수이므로 $\alpha$는 $r$의 약수여야 한다.

**$\omega$의 성질.** $\omega$는 $x^3 - 1 = (x-1)(x^2+x+1) = 0$의 근이므로 $\omega^3 = 1$이다. $\omega \ne 1$이므로 $x - 1$이 아니라 $x^2 + x + 1$ 쪽이 $0$이 되어 $\omega^2 + \omega + 1 = 0$이다. 계수가 실수인 이차방정식의 허근은 켤레로 짝을 이루므로 다른 근은 $\bar{\omega}$이고, 근과 계수의 관계에서
$$
\omega + \bar{\omega} = -1, \qquad \omega\bar{\omega} = 1
$$
이다. 마지막 식과 $\omega^3 = 1$에서 $\bar{\omega} = \dfrac{1}{\omega} = \dfrac{\omega^3}{\omega} = \omega^2$을 얻는다.

**치환과 $A^2 - B^2$.** $x^4 + x^2 + 1$은 $X = x^2$으로 놓으면 $X^2 + X + 1$인데 실수 범위에서 인수분해되지 않는다. 그래서 $x^4 + 2x^2 + 1$을 만들기 위해 $x^2$을 더하고 빼서
$$
x^4 + x^2 + 1 = (x^4 + 2x^2 + 1) - x^2 = (x^2+1)^2 - x^2 = (x^2 + x + 1)(x^2 - x + 1)
$$
로 합차 공식을 쓴다.

## 대표 예제

**예제 1 (교과서 수준).** 삼차방정식 $x^3 - 2x^2 - 5x + 6 = 0$을 푸시오.

$f(x) = x^3 - 2x^2 - 5x + 6$이라 하면 상수항 $6$의 약수 중 $f(1) = 1 - 2 - 5 + 6 = 0$이다. 조립제법으로 $x - 1$로 나누면 계수 $1,\ -2,\ -5,\ 6$에서 몫의 계수 $1,\ -1,\ -6$, 나머지 $0$을 얻는다. 따라서
$$
f(x) = (x-1)(x^2 - x - 6) = (x-1)(x-3)(x+2)
$$
이고 해는 $x = -2,\ 1,\ 3$이다.

확인: $f(3) = 27 - 18 - 15 + 6 = 0$, $f(-2) = -8 - 8 + 10 + 6 = 0$.

**예제 2 (교과서 수준).** (1) $x^4 - 5x^2 + 4 = 0$을 푸시오. (2) 연립방정식 $x - y = 1$, $x^2 + y^2 = 13$을 푸시오.

(1) $x^2 = X$로 놓으면 $X^2 - 5X + 4 = (X-1)(X-4) = 0$이므로 $X = 1$ 또는 $X = 4$. $x^2 = 1$에서 $x = \pm 1$, $x^2 = 4$에서 $x = \pm 2$. 해는 $x = -2,\ -1,\ 1,\ 2$.

확인: $x = 2$이면 $16 - 20 + 4 = 0$.

(2) 첫 식에서 $y = x - 1$을 둘째 식에 대입하면 $x^2 + (x-1)^2 = 13$, $2x^2 - 2x - 12 = 0$, $x^2 - x - 6 = 0$, $(x-3)(x+2) = 0$. $x = 3$이면 $y = 2$, $x = -2$이면 $y = -3$. 해는 $(3,\,2)$, $(-2,\,-3)$.

확인: $9 + 4 = 13$, $4 + 9 = 13$이고 $3 - 2 = 1$, $-2 - (-3) = 1$.

**예제 3 (심화).** $x^3 = 1$의 한 허근을 $\omega$라 할 때, 다음 값을 구하시오. (1) $\omega^{100} + \omega^{50} + 1$ (2) $\dfrac{\omega}{1 + \omega^2} + \dfrac{\omega^2}{1 + \omega}$

(1) $\omega^3 = 1$이므로 지수를 $3$으로 나눈 나머지만 남는다. $100 = 3 \times 33 + 1$이므로 $\omega^{100} = (\omega^3)^{33}\omega = \omega$, $50 = 3 \times 16 + 2$이므로 $\omega^{50} = \omega^2$. 따라서 값은 $\omega + \omega^2 + 1 = 0$.

(2) $\omega^2 + \omega + 1 = 0$에서 $1 + \omega^2 = -\omega$, $1 + \omega = -\omega^2$이다. 따라서
$$
\frac{\omega}{-\omega} + \frac{\omega^2}{-\omega^2} = -1 + (-1) = -2.
$$

확인: 통분해서 다시 계산하면 분자는 $\omega(1+\omega) + \omega^2(1+\omega^2) = \omega + \omega^2 + \omega^2 + \omega^4 = \omega + 2\omega^2 + \omega = 2(\omega + \omega^2) = -2$, 분모는 $(1+\omega^2)(1+\omega) = (-\omega)(-\omega^2) = \omega^3 = 1$. 값은 $-2$로 같다.

## 자주 하는 실수와 오개념

**실수 1. 조립제법에서 빠진 차수의 계수 $0$을 쓰지 않는다.**

- **왜 틀리는가:** $x^3 - 7x + 6$을 조립제법할 때 계수를 $1,\ -7,\ 6$으로 적으면 $x^2$항 자리가 사라져 몫이 완전히 틀어진다.
- **어떻게 바로잡는가:** 최고차부터 상수항까지 모든 차수를 빠짐없이 적는다. 이 예에서는 $1,\ 0,\ -7,\ 6$이고, $x - 1$로 나누면 몫은 $x^2 + x - 6$이다. 마지막에 몫과 인수를 곱해 원래 식이 나오는지 전개해 본다.

**실수 2. 복이차방정식에서 $X$의 값을 그대로 답으로 쓰거나, $X < 0$인 경우를 버린다.**

- **왜 틀리는가:** $X = x^2$이므로 구한 것은 $x^2$의 값이지 $x$가 아니다. 또 복소수 범위에서 풀라고 했는데 $x^2 = -3$을 "해가 없다"고 버리면 허근 $\pm\sqrt{3}\,i$를 놓친다.
- **어떻게 바로잡는가:** 치환한 문자는 반드시 원래 문자로 되돌린다. 문제에 "실근"이라는 말이 없으면 허근까지 모두 쓰고, 사차방정식이면 근이 $4$개인지 세어 본다.

**실수 3. $x^2 - x + 1 = 0$의 근에도 $\omega^3 = 1$, $\omega^2 + \omega + 1 = 0$을 쓴다.**

- **왜 틀리는가:** 문제마다 $\omega$라는 같은 기호를 써서 성질도 같다고 착각한다. $x^2 - x + 1 = 0$의 근은 $x^3 + 1 = (x+1)(x^2-x+1) = 0$에서 나오므로 $\omega^3 = -1$이다.
- **어떻게 바로잡는가:** $\omega$가 나오면 먼저 "어떤 방정식의 근인가"를 확인하고, 그 이차식에 $(x - 1)$ 또는 $(x + 1)$을 곱해 $\omega^3$의 값을 스스로 유도한다.

**실수 4. 연립이차방정식의 해를 짝짓지 않거나 경우 하나를 빠뜨린다.**

- **왜 틀리는가:** $x = 3,\ -2$와 $y = 2,\ -3$을 따로 구해 $(3,\,-3)$ 같은 엉뚱한 짝을 만들거나, $(x - y)(x - 2y) = 0$에서 $x = y$인 경우만 풀고 $x = 2y$인 경우를 잊는다.
- **어떻게 바로잡는가:** $x$ 하나를 구할 때마다 바로 대입식으로 짝인 $y$를 구해 순서쌍으로 적는다. 인수분해로 경우를 나눴다면 각 경우를 번호를 붙여 끝까지 푼다.

## 앞뒤 학년 연계

나머지정리·인수정리와 인수분해, 복소수와 이차방정식의 근과 계수의 관계가 이 단원의 도구다. 여기서 찾은 근들은 다음 단원에서 이차부등식의 해 구간을 나누는 경계점이 되고, 이후 미분을 배우면 삼차함수의 그래프와 방정식의 실근 개수를 연결해서 보게 된다.
