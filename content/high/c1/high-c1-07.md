## 핵심 개념

> **한 줄 요약.** 연립부등식은 각각 풀어 수직선에서 겹치는 부분을 읽고, 절댓값 부등식은 "거리"로 보거나 구간을 나누며, 이차부등식은 그래프가 $x$축보다 위인지 아래인지로 읽는다.

방정식이 "딱 맞는 값"을 찾는 것이라면 부등식은 "조건을 만족하는 값의 범위"를 찾는 것이다. 그래서 답이 점 하나가 아니라 수직선 위의 구간으로 나오고, 경계점을 포함하는지(등호가 있는지)가 늘 중요하다. 이 단원의 모든 문제는 결국 "수직선 위에 범위를 그리고 읽는 일"로 정리된다.

**생활 속에서.** "체온이 $36.5\,^\circ\text{C}$에서 $0.5\,^\circ\text{C}$ 이상 벗어나면 이상"은 $|t - 36.5| \ge 0.5$라는 절댓값 부등식이다. 위로 던진 공이 일정 높이 이상에 머무는 시간, 이익이 손해가 되지 않는 판매량 범위처럼 "언제부터 언제까지"를 묻는 문제는 이차부등식이 된다(대표 예제 4).

**연립일차부등식.** 두 개 이상의 일차부등식을 한 쌍으로 묶은 것으로, 모든 부등식을 **동시에** 만족하는 $x$의 범위가 해다. 각 부등식의 해를 수직선 위에 나타낸 뒤 겹치는 부분(공통 범위)을 읽는다. $A < B < C$ 꼴은 "$A < B$이고 $B < C$"인 연립부등식이다.

**절댓값이 있는 부등식.** $|x|$는 수직선에서 $0$과 $x$ 사이의 거리다. 그래서 $|x| < 3$은 "원점에서 거리가 $3$보다 작은 점"이므로 $-3 < x < 3$이다. 절댓값이 두 개 이상이거나 모양이 복잡하면, 절댓값 안이 $0$이 되는 $x$를 기준으로 구간을 나누어 각 구간에서 절댓값 기호를 없앤 뒤 푼다.

**이차부등식.** $ax^2 + bx + c > 0$처럼 모든 항을 한쪽으로 옮겼을 때 이차식이 되는 부등식이다. 이차부등식의 해는 이차함수 $y = ax^2 + bx + c$의 그래프로 읽는 것이 가장 확실하다. $y > 0$인 $x$의 범위는 그래프가 $x$축보다 **위**에 있는 부분, $y < 0$인 범위는 **아래**에 있는 부분이다.

**연립이차부등식.** 이차부등식이 하나 이상 섞인 연립부등식이다. 각 부등식을 따로 푼 뒤 공통 범위를 구한다는 점은 연립일차부등식과 같다.

이차부등식을 그래프로 읽는 방법을 그림으로 보자. 아래로 볼록한 포물선 $y = (x+2)(x-3)$은 $x$축과 $x = -2$, $x = 3$에서 만난다. 두 교점 사이의 그래프(주황)는 $x$축 아래에 있고, $x < -2$와 $x > 3$ 쪽은 $x$축 위로 올라간다.

따라서 $(x+2)(x-3) < 0$의 해는 $-2 < x < 3$, $(x+2)(x-3) > 0$의 해는 $x < -2$ 또는 $x > 3$이다.

## 공식·정리

**연립부등식**: 각 부등식의 해를 수직선에 모두 나타낸 뒤 **모든 부등식이 겹치는 부분**이 해다. 겹치는 부분이 없으면 해는 없다. $A < B < C$는 $A < B$와 $B < C$를 연립한 것이다.

**절댓값 부등식** ($a > 0$일 때)

$$
|x| < a \iff -a < x < a, \qquad |x| > a \iff x < -a \ \text{또는}\ x > a
$$

같은 원리로 $|x - m| < a \iff m - a < x < m + a$($m$에서 거리가 $a$ 미만). $a \le 0$이면 $|x| < a$는 해가 없고 $|x| > a$는 ($a = 0$일 때 $x \ne 0$, $a < 0$일 때 모든 실수) 다르게 처리해야 하므로 부호를 먼저 확인한다.

**이차부등식의 해** ($a > 0$, $D = b^2 - 4ac$, 두 실근 $\alpha < \beta$ 또는 중근 $\alpha$)

| 부등식 | $D > 0$ | $D = 0$ | $D < 0$ |
| --- | --- | --- | --- |
| $ax^2 + bx + c > 0$ | $x < \alpha$ 또는 $x > \beta$ | $x \ne \alpha$인 모든 실수 | 모든 실수 |
| $ax^2 + bx + c \ge 0$ | $x \le \alpha$ 또는 $x \ge \beta$ | 모든 실수 | 모든 실수 |
| $ax^2 + bx + c < 0$ | $\alpha < x < \beta$ | 해는 없다 | 해는 없다 |
| $ax^2 + bx + c \le 0$ | $\alpha \le x \le \beta$ | $x = \alpha$ | 해는 없다 |

- $a < 0$이면 양변에 $-1$을 곱해 $a > 0$으로 바꾸고 **부등호 방향을 뒤집은** 뒤 표를 쓴다.
- 모든 실수 $x$에 대하여 $ax^2 + bx + c > 0$이 성립할 조건($a \ne 0$): $a > 0$이고 $D < 0$.

## 왜 성립하는가

**그래프로 푸는 이유.** 부등식 $ax^2 + bx + c > 0$은 "식의 값이 양수인 $x$를 모두 찾아라"는 뜻이다. 함수 $y = ax^2 + bx + c$의 그래프에서 점의 높이가 바로 식의 값이므로, 값이 양수인 $x$는 그래프가 $x$축 위에 있는 $x$와 같다. 방정식 $ax^2 + bx + c = 0$의 실근은 그래프가 $x$축을 지나가는 지점이므로, 부호는 근에서만 바뀌고 근과 근 사이에서는 일정하다.

**$D > 0$일 때 식으로 확인.** $a > 0$이고 두 근이 $\alpha < \beta$이면 $ax^2 + bx + c = a(x - \alpha)(x - \beta)$이다. $x < \alpha$이면 두 인수가 모두 음수라 곱이 양수, $\alpha < x < \beta$이면 $(x-\alpha) > 0$, $(x - \beta) < 0$이라 곱이 음수, $x > \beta$이면 둘 다 양수라 곱이 양수다. 이것이 표의 첫 열이다.

**$D \le 0$일 때.** 완전제곱식으로 바꾸면

$$
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{D}{4a}
$$

이다. $a > 0$이고 $D < 0$이면 첫째 항은 $0$ 이상, 둘째 항 $-\dfrac{D}{4a}$는 양수이므로 식의 값은 **항상 양수**다. 그래서 $> 0$의 해는 모든 실수, $< 0$의 해는 없다. $D = 0$이면 식이 $a\left(x + \dfrac{b}{2a}\right)^2$이 되어 중근에서만 $0$이고 나머지에서는 양수다.

**절댓값 부등식에서 범위를 나누는 이유.** 절댓값의 정의는 $|A| = A$ ($A \ge 0$), $|A| = -A$ ($A < 0$)로 두 경우로 나뉜다. 그래서 절댓값 안의 부호가 정해지는 구간마다 식이 달라지고, 구간별로 풀어 얻은 해는 반드시 **그 구간 안에 있는 것만** 남겨야 한다.

## 대표 예제

**예제 1 (기본).** 연립부등식 $\begin{cases} 2x - 1 < x + 3 \\ 3x + 2 \ge x - 4 \end{cases}$를 푸시오.

풀이 전략: 두 부등식을 각각 풀고, 수직선에 함께 그려 겹치는 부분을 읽는다. 끝점의 포함 여부는 등호로 판단한다.

1. 첫 식: $2x - x < 3 + 1$에서 $x < 4$.
2. 둘째 식: $3x - x \ge -4 - 2$, $2x \ge -6$에서 $x \ge -3$.
3. 공통 범위는 $-3 \le x < 4$.

```numberline
title: x < 4 와 x ≥ −3 이 겹치는 부분 −3 ≤ x < 4 가 연립부등식의 해. −3 은 포함(색칠한 점), 4 는 제외(빈 점)
range: [-5, 6]
draw:
  - ray: 4
    dir: left
    open: true
  - ray: -3
    label: 위는 x ≥ −3, 아래는 x < 4
```

확인: $x = -3$이면 $-7 < 0$, $-7 \ge -7$로 둘 다 성립. $x = 4$이면 $7 < 7$이 거짓이므로 $4$는 빠지는 것이 맞다.

**예제 2 (기본).** 부등식 $|2x - 3| \le 5$를 푸시오.

풀이 전략: $|A| \le 5 \iff -5 \le A \le 5$를 쓴 뒤, 세 변에 같은 연산을 한다.

1. $-5 \le 2x - 3 \le 5$.
2. 각 변에 $3$을 더하면 $-2 \le 2x \le 8$.
3. 각 변을 $2$로 나누면 $-1 \le x \le 4$.

```numberline
title: "|2x − 3| ≤ 5 의 해 −1 ≤ x ≤ 4. 가운데 3/2 에서 양쪽으로 5/2 씩 떨어진 범위다"
range: [-2, 5]
draw:
  - interval: [-1, 4]
    label: −1 ≤ x ≤ 4
```

확인: $x = 4$이면 $|5| = 5 \le 5$, $x = -1$이면 $|-5| = 5 \le 5$. 식을 $2\left|x - \dfrac{3}{2}\right| \le 5$로 보면 "$\dfrac{3}{2}$에서 거리가 $\dfrac{5}{2}$ 이하"라는 뜻이라 그림처럼 가운데가 $\dfrac{3}{2}$이다.

**예제 3 (표준).** 다음 이차부등식을 푸시오. (1) $x^2 - x - 6 > 0$ (2) $-x^2 + 4x - 4 \ge 0$ (3) $x^2 + 2x + 5 > 0$

풀이 전략: $x^2$의 계수를 양수로 맞추고, 인수분해(또는 판별식)로 그래프가 $x$축과 어디서 만나는지 확인한 뒤 위·아래를 읽는다.

(1) $(x+2)(x-3) > 0$이고 아래로 볼록이므로 그래프가 $x$축 위에 있는 두 근의 바깥쪽: $x < -2$ 또는 $x > 3$. (핵심 개념의 그림과 같다.)

(2) 양변에 $-1$을 곱하면 부등호가 뒤집혀 $x^2 - 4x + 4 \le 0$, 즉 $(x-2)^2 \le 0$. 제곱은 음수가 될 수 없으므로 $(x-2)^2 = 0$인 $x = 2$만 해다.

(3) $\dfrac{D}{4} = 1 - 5 = -4 < 0$이고 $x^2$의 계수가 양수이므로 그래프가 통째로 $x$축 위에 있다. 해는 모든 실수.

확인: (1) $x = 4$이면 $16 - 4 - 6 = 6 > 0$, $x = 0$이면 $-6$으로 해가 아니다. (3) $x^2 + 2x + 5 = (x+1)^2 + 4 \ge 4$이므로 항상 양수.

**예제 4 (응용).** 지면에서 공을 똑바로 위로 던졌을 때, $t$초 후 공의 높이가 $h = -5t^2 + 20t\,(\text{m})$라고 하자. 공의 높이가 $15\,\text{m}$ 이상인 시간은 몇 초 동안인지 구하시오.

풀이 전략: "높이 $15$ 이상"을 이차부등식으로 쓰고, $t^2$의 계수를 양수로 바꿔 푼다. 시간은 $t \ge 0$이고 공이 땅에 떨어지기 전($h \ge 0$)이어야 한다.

1. $-5t^2 + 20t \ge 15$에서 $-5t^2 + 20t - 15 \ge 0$.
2. 양변을 $-5$로 나누면 부등호가 뒤집혀 $t^2 - 4t + 3 \le 0$, $(t - 1)(t - 3) \le 0$.
3. 따라서 $1 \le t \le 3$. 이 범위는 $t \ge 0$이고 공이 떨어지는 $t = 4$보다 앞이므로 모두 의미가 있다.

공은 던진 지 $1$초부터 $3$초까지, 모두 $2$초 동안 $15\,\text{m}$ 이상에 있다.

확인: $t = 1$이면 $-5 + 20 = 15$, $t = 3$이면 $-45 + 60 = 15$, $t = 2$이면 $-20 + 40 = 20 \ge 15$.

**예제 5 (심화).** (1) 부등식 $|x - 1| + |x + 2| < 5$를 푸시오. (2) 연립부등식 $\begin{cases} x^2 - 4x - 5 \le 0 \\ x^2 - x - 2 > 0 \end{cases}$을 푸시오.

풀이 전략: (1) 절댓값이 두 개이므로 안이 $0$이 되는 $x = -2$, $x = 1$로 구간을 셋으로 나누고, 구간마다 "가정한 범위와 구한 범위의 공통 부분"만 남긴다. (2) 두 이차부등식을 각각 풀어 수직선에서 겹치는 부분을 찾는다.

(1) 구간별로 푼다.

- $x < -2$: $-(x-1) - (x+2) = -2x - 1 < 5$에서 $x > -3$. 구간과 합치면 $-3 < x < -2$.
- $-2 \le x < 1$: $-(x-1) + (x+2) = 3 < 5$로 항상 성립. $-2 \le x < 1$.
- $x \ge 1$: $(x-1) + (x+2) = 2x + 1 < 5$에서 $x < 2$. 구간과 합치면 $1 \le x < 2$.

세 경우를 모으면 $-3 < x < 2$.

확인: $x = -3$이면 $4 + 1 = 5$로 등호이므로 제외, $x = 2$이면 $1 + 4 = 5$로 제외. $x = 0$이면 $1 + 2 = 3 < 5$로 성립. 수직선에서 $x$가 $1$과 $-2$까지 거리의 합이 $5$ 미만인 점이라고 해석해도 같은 답이 나온다.

(2) $x^2 - 4x - 5 = (x-5)(x+1) \le 0$에서 $-1 \le x \le 5$. $x^2 - x - 2 = (x-2)(x+1) > 0$에서 $x < -1$ 또는 $x > 2$. 공통 범위는 $2 < x \le 5$.

```numberline
title: 맨 아래 선(−1 ≤ x ≤ 5)과 위의 화살표(x < −1 또는 x > 2)가 겹치는 부분은 2 < x ≤ 5 뿐이다
range: [-3, 7]
draw:
  - interval: [-1, 5]
  - ray: -1
    dir: left
    open: true
    label: x < −1
  - ray: 2
    open: true
    label: x > 2
```

확인: $x = 5$이면 $0 \le 0$, $25 - 5 - 2 = 18 > 0$으로 성립. $x = -1$은 둘째 식이 $0 > 0$으로 거짓이라 빠진다. 그림에서 $x < -1$ 부분은 $-1 \le x \le 5$와 겹치지 않는다.

3. 모든 실수 $x$에 대하여 $x^2 + kx + 4 > 0$이 성립하도록 하는 실수 $k$의 값의 범위를 구하시오.

## 자주 하는 실수와 오개념

**실수 1. 이차부등식의 부등호 방향과 해 구간을 거꾸로 짝짓는다.**

- **왜 틀리는가:** $(x+2)(x-3) < 0$의 해를 "$x < -2$ 또는 $x > 3$"이라고 쓴다. "작다"는 말에 끌려 바깥쪽 범위를 고르는 것이다.
- **어떻게 바로잡는가:** 외우지 말고 매번 아래로 볼록한 포물선을 간단히 그린다. 두 근 사이는 $x$축 아래(음수), 바깥은 $x$축 위(양수)다. 답을 쓴 뒤 구간 안의 수 하나(예: $x = 0$)를 넣어 부호를 확인한다.

**실수 2. $x^2$의 계수가 음수인데 그대로 표를 쓰거나, $-1$을 곱하고 부등호를 뒤집지 않는다.**

- **왜 틀리는가:** 표는 $a > 0$인 경우에 만든 것이다. $-x^2 + x + 6 > 0$을 $(x+2)(x-3) > 0$으로 바꾸면 부등호가 뒤집히지 않아 정반대 답이 나온다.
- **어떻게 바로잡는가:** 먼저 $x^2$의 계수를 양수로 만들고, 그때 부등호를 반드시 뒤집는다. 이 예의 바른 식은 $(x+2)(x-3) < 0$, 해는 $-2 < x < 3$이다.

**실수 3. $D < 0$이면 무조건 "해가 없다"고 쓴다.**

- **왜 틀리는가:** 방정식 $x^2 + 2x + 5 = 0$은 실근이 없지만, 부등식 $x^2 + 2x + 5 > 0$은 모든 실수에서 성립한다. "방정식의 실근이 없다"와 "부등식의 해가 없다"를 혼동한 것이다.
- **어떻게 바로잡는가:** $D < 0$이면 그래프가 $x$축과 만나지 않고 통째로 위(또는 아래)에 떠 있다. 부등호가 그 쪽을 묻는지 보고 "모든 실수" 또는 "해는 없다"를 고른다.

**실수 4. 절댓값 부등식에서 구간별 해를 그 구간과 겹치지 않고 그대로 모은다.**

- **왜 틀리는가:** $x \ge 1$ 구간에서 $x < 2$를 얻고 답에 "$x < 2$"를 통째로 넣으면, 이 구간 가정과 맞지 않는 $x < 1$까지 섞인다.
- **어떻게 바로잡는가:** 구간마다 "가정한 범위 ∩ 구한 범위"를 적고, 마지막에 세 결과를 합한다. 경계점($x = -2$, $x = 1$)이 어느 구간에 속하는지도 정해 둔다.

**실수 5. $A < B < C$를 $A < C$로 바꿔 푼다.**

- **왜 틀리는가:** $x - 1 < 2x + 1 < x + 5$에서 가운데를 빼고 $x - 1 < x + 5$를 풀면 "모든 실수"라는 엉뚱한 답이 나온다. $A < B < C$는 $A < B$와 $B < C$를 **동시에** 만족해야 한다는 뜻이다.
- **어떻게 바로잡는가:** 두 부등식으로 나눠 쓴다. $x - 1 < 2x + 1$에서 $x > -2$, $2x + 1 < x + 5$에서 $x < 4$이므로 해는 $-2 < x < 4$이다.
