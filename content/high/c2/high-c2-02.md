## 핵심 개념

**직선의 방정식**은 직선 위의 모든 점 $(x,\,y)$가 만족하고, 직선 밖의 점은 만족하지 않는 $x$, $y$에 대한 등식이다. 중학교의 일차함수 $y = ax + b$는 직선의 방정식의 한 종류이고, 고등학교에서는 $y$축에 평행한 직선 $x = k$까지 포함해 모든 직선을 다룬다.

**기울기**는 $x$의 값이 $1$만큼 늘 때 $y$의 값이 늘어난 양이다. 직선 위 두 점 $(x_1,\,y_1)$, $(x_2,\,y_2)$에 대해 $\dfrac{y_2 - y_1}{x_2 - x_1}$로 구한다. $x_1 = x_2$인 직선(세로선)은 분모가 $0$이 되어 **기울기가 정의되지 않는다.**

**일반형** $ax + by + c = 0$ ($a$, $b$ 중 적어도 하나는 $0$이 아님)은 모든 직선을 하나의 꼴로 나타낸다. $b \ne 0$이면 $y = -\dfrac{a}{b}x - \dfrac{c}{b}$로 기울기가 $-\dfrac{a}{b}$인 직선이고, $b = 0$이면 $x = -\dfrac{c}{a}$인 세로선이다.

**점과 직선 사이의 거리**는 점에서 직선에 내린 수선의 발까지의 거리, 즉 점에서 직선 위의 점까지의 거리 중 가장 짧은 거리다.

**그림 설명:** 원점을 지나는 두 직선 $y = m_1 x$, $y = m_2 x$를 그리고, 세로선 $x = 1$과 만나는 점을 각각 $\mathrm{A}(1,\,m_1)$, $\mathrm{B}(1,\,m_2)$로 표시한다. 두 직선이 수직이면 삼각형 $\mathrm{OAB}$는 $\mathrm{O}$에서 직각인 직각삼각형이 된다.

## 공식·정리

**직선의 방정식 구하기**
- 기울기가 $m$이고 점 $(x_1,\,y_1)$을 지나는 직선: $y - y_1 = m(x - x_1)$
- 두 점 $(x_1,\,y_1)$, $(x_2,\,y_2)$를 지나는 직선
  - $x_1 \ne x_2$일 때: $y - y_1 = \dfrac{y_2 - y_1}{x_2 - x_1}(x - x_1)$
  - $x_1 = x_2$일 때: $x = x_1$ (기울기 없음)
- $x$절편 $a$, $y$절편 $b$인 직선 (조건: $a \ne 0$, $b \ne 0$): $\dfrac{x}{a} + \dfrac{y}{b} = 1$
- 일반형: $ax + by + c = 0$ (조건: $a \ne 0$ 또는 $b \ne 0$)

**두 직선의 위치 관계** — 기울기 꼴 $y = m_1 x + n_1$, $y = m_2 x + n_2$일 때
- 평행: $m_1 = m_2$, $n_1 \ne n_2$ (기울기도 절편도 같으면 일치)
- 수직: $m_1 m_2 = -1$ (두 직선 모두 기울기가 있을 때만 쓸 수 있음)

**일반형** $ax + by + c = 0$, $a'x + b'y + c' = 0$일 때 (세로선까지 포함)
- 평행: $ab' - a'b = 0$ 이고 두 직선이 일치하지 않음. 계수가 모두 $0$이 아니면 $\dfrac{a}{a'} = \dfrac{b}{b'} \ne \dfrac{c}{c'}$
- 수직: $aa' + bb' = 0$

**점과 직선 사이의 거리**: 점 $(x_1,\,y_1)$과 직선 $ax + by + c = 0$ 사이의 거리는
$$d = \dfrac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$$
- 직선은 반드시 "$\cdots = 0$" 꼴로 고친 뒤 대입한다.
- 평행한 두 직선 $ax + by + c = 0$, $ax + by + c' = 0$ 사이의 거리는 $\dfrac{|c - c'|}{\sqrt{a^2 + b^2}}$.

## 왜 성립하는가

**한 점과 기울기.** 점 $(x, y)$가 직선 위에 있으면 $(x_1,\,y_1)$과 이은 기울기가 $m$이므로 $\dfrac{y - y_1}{x - x_1} = m$이다. 양변에 $x - x_1$을 곱하면 $y - y_1 = m(x - x_1)$이고, 이 꼴은 $x = x_1$인 점 $(x_1,\,y_1)$ 자신도 포함한다. 절편형은 두 점 $(a,\,0)$, $(0,\,b)$를 지나는 직선 $y = -\dfrac{b}{a}x + b$의 양변을 $b$로 나누고 정리한 것이다.

**수직 조건 $m_1 m_2 = -1$.** 직선을 평행이동해도 기울기와 각은 변하지 않으므로, 두 직선이 원점을 지난다고 해도 된다. 그림 설명의 $\mathrm{A}(1,\,m_1)$, $\mathrm{B}(1,\,m_2)$에 대해 두 직선이 수직일 필요충분조건은 $\overline{\mathrm{OA}}^2 + \overline{\mathrm{OB}}^2 = \overline{\mathrm{AB}}^2$ (피타고라스 정리와 그 역)이다.

$$\begin{aligned} (1 + m_1^2) + (1 + m_2^2) &= (m_1 - m_2)^2 \\ 2 + m_1^2 + m_2^2 &= m_1^2 - 2m_1 m_2 + m_2^2 \\ m_1 m_2 &= -1 \end{aligned}$$

세로선 $x = 1$을 썼기 때문에 이 증명은 두 직선 모두 기울기가 있을 때만 통한다. 세로선과 가로선의 수직은 일반형 조건 $aa' + bb' = 0$으로 판정한다.

**점과 직선 사이의 거리.** 먼저 $a \ne 0$, $b \ne 0$인 경우를 보자. 점 $\mathrm{P}(x_1,\,y_1)$에서 직선에 내린 수선의 발을 $\mathrm{H}(x_2,\,y_2)$라 하자. 직선의 기울기는 $-\dfrac{a}{b}$이므로 $\mathrm{PH}$의 기울기는 $\dfrac{b}{a}$이고, $\dfrac{y_2 - y_1}{x_2 - x_1} = \dfrac{b}{a}$에서 $\dfrac{x_2 - x_1}{a} = \dfrac{y_2 - y_1}{b}$이다. 이 값을 $k$라 하면 $x_2 = x_1 + ak$, $y_2 = y_1 + bk$이다. ($\mathrm{P}$가 직선 위에 있으면 $k = 0$이다.)

$\mathrm{H}$가 직선 위에 있으므로

$$\begin{aligned} a(x_1 + ak) + b(y_1 + bk) + c &= 0 \\ (a^2 + b^2)k &= -(ax_1 + by_1 + c) \\ k &= -\dfrac{ax_1 + by_1 + c}{a^2 + b^2} \end{aligned}$$

따라서

$$\overline{\mathrm{PH}} = \sqrt{(ak)^2 + (bk)^2} = |k|\sqrt{a^2 + b^2} = \dfrac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$$

$a = 0$이면 직선은 가로선 $y = -\dfrac{c}{b}$이고 거리는 $\left|y_1 + \dfrac{c}{b}\right| = \dfrac{|by_1 + c|}{|b|}$로 공식과 같다. $b = 0$일 때도 마찬가지다.

## 대표 예제

**예제 1 (교과서 수준).** 두 점 $(2,\,-1)$, $(4,\,3)$을 지나는 직선 $l$의 방정식을 구하고, 점 $(1,\,1)$을 지나고 $l$에 수직인 직선의 방정식을 구하시오.

$l$의 기울기는 $\dfrac{3 - (-1)}{4 - 2} = 2$이므로 $y + 1 = 2(x - 2)$, 즉 $y = 2x - 5$. 확인: $x = 4$이면 $y = 3$.

수직인 직선의 기울기 $m$은 $2m = -1$에서 $m = -\dfrac{1}{2}$. 따라서 $y - 1 = -\dfrac{1}{2}(x - 1)$, 정리하면 $x + 2y - 3 = 0$. 확인: $(1,\,1)$을 넣으면 $1 + 2 - 3 = 0$이고, 일반형 수직 조건 $2 \cdot 1 + (-1) \cdot 2 = 0$도 성립한다($l$: $2x - y - 5 = 0$).

**예제 2 (교과서 수준).** 점 $(3,\,4)$와 직선 $3x + 4y - 5 = 0$ 사이의 거리를 구하시오.

$$d = \dfrac{|3 \cdot 3 + 4 \cdot 4 - 5|}{\sqrt{3^2 + 4^2}} = \dfrac{20}{5} = 4$$

확인(수선의 발로): $k = -\dfrac{20}{25} = -\dfrac{4}{5}$이므로 $\mathrm{H}\left(3 - \dfrac{12}{5},\ 4 - \dfrac{16}{5}\right) = \left(\dfrac{3}{5},\ \dfrac{4}{5}\right)$. 이 점은 $\dfrac{9}{5} + \dfrac{16}{5} - 5 = 0$으로 직선 위에 있고, $\sqrt{\left(\dfrac{12}{5}\right)^2 + \left(\dfrac{16}{5}\right)^2} = \dfrac{\sqrt{400}}{5} = 4$로 같다.

**예제 3 (심화).** 두 직선 $(a + 1)x + 2y + 1 = 0$, $x + ay - 3 = 0$이 (1) 수직일 때, (2) 평행할 때 상수 $a$의 값을 각각 구하시오.

두 번째 직선은 $a = 0$이면 세로선 $x = 3$이 되므로, 기울기 대신 일반형 조건을 쓴다.

(1) 수직: $(a + 1) \cdot 1 + 2 \cdot a = 0$에서 $3a + 1 = 0$, $a = -\dfrac{1}{3}$. 확인: 두 직선의 기울기는 $-\dfrac{a + 1}{2} = -\dfrac{1}{3}$, $-\dfrac{1}{a} = 3$이고 곱이 $-1$이다.

(2) 평행: $(a + 1) \cdot a - 2 \cdot 1 = 0$에서 $a^2 + a - 2 = 0$, $(a + 2)(a - 1) = 0$이므로 $a = 1$ 또는 $a = -2$. 일치하는지 확인해야 한다.
- $a = 1$: $2x + 2y + 1 = 0$과 $x + y - 3 = 0$. 앞 식은 $x + y + \dfrac{1}{2} = 0$이므로 일치하지 않는다(평행).
- $a = -2$: $-x + 2y + 1 = 0$, 즉 $x - 2y - 1 = 0$과 $x - 2y - 3 = 0$. 일치하지 않는다(평행).

따라서 $a = 1$ 또는 $a = -2$.

## 자주 하는 실수와 오개념

**실수 1. 세로선·가로선의 수직을 놓친다.**
왜 틀리는가: 수직 조건을 $m_1 m_2 = -1$ 하나로만 기억해서, $x = 2$와 $y = 3$처럼 기울기가 없거나 $0$인 경우 "곱이 $-1$이 안 되니 수직이 아니다"라고 판단하거나, 미지수가 들어간 문제에서 이 경우를 빠뜨린다.
어떻게 바로잡는가: $m_1 m_2 = -1$은 두 직선 모두 기울기가 있을 때만 쓴다. 계수에 미지수가 있으면 일반형 조건 $aa' + bb' = 0$을 써서 세로선 경우까지 한 번에 처리한다.

**실수 2. 평행 조건에서 일치하는 경우를 빼지 않는다.**
왜 틀리는가: 기울기가 같다는 조건만 풀고 끝내서, 두 직선이 완전히 겹치는 값까지 답에 넣는다.
어떻게 바로잡는가: 평행은 "기울기 같고 절편 다름"이다. 구한 값을 원래 두 식에 넣어 같은 직선이 되는지 반드시 확인한다(예제 3).

**실수 3. 점과 직선 사이 거리에서 식을 "$= 0$" 꼴로 고치지 않고 대입한다.**
왜 틀리는가: $y = 2x + 1$을 보고 $a = 2$, $b = 1$, $c = 1$처럼 계수를 읽는다. 공식은 $ax + by + c = 0$ 꼴의 계수를 쓴다.
어떻게 바로잡는가: 먼저 $2x - y + 1 = 0$으로 바꾼 뒤 $a = 2$, $b = -1$, $c = 1$을 읽는다. 분자의 절댓값도 빼먹지 않는다.

**실수 4. 원점을 지나는 직선에 절편형을 쓴다.**
왜 틀리는가: $\dfrac{x}{a} + \dfrac{y}{b} = 1$은 $a \ne 0$, $b \ne 0$일 때만 가능하다. 두 절편이 같다는 문제에서 $\dfrac{x}{a} + \dfrac{y}{a} = 1$만 풀면 원점을 지나는 직선($y = mx$ 꼴)이 빠진다.
어떻게 바로잡는가: 절편 조건 문제에서는 "원점을 지나는 경우"를 따로 확인하는 습관을 들인다.

## 앞뒤 학년 연계

중2의 일차함수와 그래프에서 기울기와 $y$절편을 배운 것이 출발점이고, 평면좌표의 거리 공식과 피타고라스 정리가 수직 조건과 거리 공식의 증명에 쓰인다. 점과 직선 사이의 거리는 다음 단원에서 원과 직선의 위치 관계, 접선 판정에 그대로 쓰인다.
