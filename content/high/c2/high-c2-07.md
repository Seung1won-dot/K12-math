## 핵심 개념

**함수와 정의역·공역·치역.** 두 집합 $X$, $Y$에 대하여 $X$의 각 원소에 $Y$의 원소가 **오직 하나씩** 대응할 때, 이 대응을 $X$에서 $Y$로의 **함수**라 하고 $f : X \to Y$로 쓴다. $X$를 **정의역**, $Y$를 **공역**이라 하고, 함숫값 $f(x)$ 전체의 집합 $\{f(x) \mid x \in X\}$를 **치역**이라고 한다. 치역은 공역의 부분집합이지만 공역과 같을 필요는 없다.

**서로 같은 함수와 그래프.** 두 함수 $f$, $g$는 정의역과 공역이 각각 같고 정의역의 모든 $x$에서 $f(x) = g(x)$일 때 **서로 같다**고 한다. 식이 달라 보여도 같은 함수일 수 있고, 식이 같아도 정의역이 다르면 다른 함수다. 순서쌍 $(x,\,f(x))$ 전체의 집합을 함수 $f$의 **그래프**라고 한다.

**일대일함수와 일대일대응.** 정의역의 서로 다른 원소에 서로 다른 함숫값이 대응하는 함수, 즉 $x_1 \ne x_2$이면 $f(x_1) \ne f(x_2)$인 함수를 **일대일함수**라고 한다. 일대일함수이면서 치역과 공역이 같은 함수를 **일대일대응**이라고 한다. 이 밖에 $f(x) = x$인 **항등함수** $I$, 모든 $x$에 같은 값이 대응하는 **상수함수**가 있다.

**합성함수.** 두 함수 $f : X \to Y$, $g : Y \to Z$에 대하여 $x$에 $g(f(x))$를 대응시키는 함수를 $f$와 $g$의 **합성함수**라 하고 $g \circ f$로 쓴다. 기호에서 **오른쪽에 있는 $f$를 먼저** 적용한다는 점이 중요하다.

**역함수.** 함수 $f : X \to Y$가 일대일대응이면 $Y$의 각 원소 $y$에 $y = f(x)$인 $X$의 원소 $x$가 하나씩 정해진다. 이 대응을 $f$의 **역함수**라 하고 $f^{-1} : Y \to X$로 쓴다. 즉 $y = f(x) \iff x = f^{-1}(y)$이다.

**그림 설명:** 왼쪽 타원 $X = \{1,\,2,\,3\}$과 오른쪽 타원 $Y = \{a,\,b,\,c\}$를 그리고 $1 \to b$, $2 \to c$, $3 \to a$로 화살표를 긋는다. 화살표가 겹치지 않고 $Y$의 모든 원소가 화살표를 하나씩 받으므로 일대일대응이다. 모든 화살표의 방향을 거꾸로 돌리면 역함수 $f^{-1}$의 그림이 된다.

## 공식·정리

**함수의 개수.** $n(X) = m$, $n(Y) = n$일 때 ($m$, $n$은 자연수)

- $X \to Y$인 함수의 개수: $n^{m}$
- 일대일함수의 개수: ${}_{n}\mathrm{P}_{m} = n(n-1)\cdots(n-m+1)$ (단, $m \le n$)
- 일대일대응의 개수: $n!$ (단, $m = n$)

**합성함수의 성질.** 합성이 정의될 때

- $(g \circ f)(x) = g(f(x))$. 이 합성은 $f$의 치역이 $g$의 정의역에 포함될 때 정의된다.
- 일반적으로 $g \circ f \ne f \circ g$ (교환법칙 불성립)
- $h \circ (g \circ f) = (h \circ g) \circ f$ (결합법칙 성립)
- $f \circ I = I \circ f = f$

**역함수의 성질.** $f : X \to Y$가 일대일대응일 때

- 역함수가 존재할 조건: $f$가 일대일대응
- $(f^{-1} \circ f)(x) = x$ ($x \in X$), $(f \circ f^{-1})(y) = y$ ($y \in Y$), $(f^{-1})^{-1} = f$
- $g$도 일대일대응이면 $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$
- 역함수 구하기: ① $y = f(x)$를 $x$에 대하여 푼다 ② $x$와 $y$를 바꾼다 ③ 정의역은 원래 함수의 치역으로 정한다.
- $y = f(x)$의 그래프와 $y = f^{-1}(x)$의 그래프는 직선 $y = x$에 대하여 대칭이다.

## 왜 성립하는가

**역함수가 일대일대응일 때만 존재하는 이유.** 역함수 $f^{-1}$도 함수이므로 $Y$의 **모든** 원소에 $X$의 원소가 **오직 하나** 대응해야 한다. $f$가 일대일함수가 아니면 $f(x_1) = f(x_2) = y$ ($x_1 \ne x_2$)인 $y$가 있어 $f^{-1}(y)$가 두 개가 되어 버린다. 치역이 공역과 다르면 어떤 $x$와도 짝지어지지 않은 $y$가 남아 $f^{-1}(y)$를 정할 수 없다. 두 문제가 모두 없는 경우가 바로 일대일대응이다.

**그래프가 $y = x$에 대하여 대칭인 이유.** 점 $(a,\,b)$가 $y = f(x)$의 그래프 위에 있으면

$$b = f(a) \iff a = f^{-1}(b) \iff \text{점 } (b,\,a) \text{가 } y = f^{-1}(x) \text{의 그래프 위에 있다}$$

두 점 $(a,\,b)$, $(b,\,a)$를 이은 선분의 중점은 $\left(\dfrac{a+b}{2},\,\dfrac{a+b}{2}\right)$로 직선 $y = x$ 위에 있다. $a \ne b$일 때 선분의 기울기는 $\dfrac{a - b}{b - a} = -1$이므로 기울기가 $1$인 $y = x$와 수직이다. 따라서 두 점은 $y = x$에 대하여 대칭이고, 그래프 전체도 대칭이다.

**$(g \circ f)^{-1} = f^{-1} \circ g^{-1}$인 이유.** 결합법칙을 이용하면

$$(f^{-1} \circ g^{-1}) \circ (g \circ f) = f^{-1} \circ (g^{-1} \circ g) \circ f = f^{-1} \circ I \circ f = f^{-1} \circ f = I$$

이므로 $f^{-1} \circ g^{-1}$이 $g \circ f$의 역함수다. 신발과 양말처럼 "나중에 한 것을 먼저 되돌린다"고 기억하면 된다.

**함수의 개수.** $X$의 원소 $m$개 각각이 $Y$의 원소 $n$개 중 하나를 고르므로 곱의 법칙으로 $n^{m}$이다. 일대일함수는 이미 고른 값을 다시 고를 수 없으므로 $n$, $n - 1$, $\dots$, $n - m + 1$가지씩 골라 ${}_{n}\mathrm{P}_{m}$이다.

## 대표 예제

**예제 1 (교과서 수준).** $X = \{-1,\,0,\,1,\,2\}$, $Y = \{0,\,1,\,2,\,3,\,4\}$에 대하여 $f : X \to Y$, $f(x) = x^{2}$이다. 치역을 구하고 $f$가 일대일함수인지 판단하시오.

$f(-1) = 1$, $f(0) = 0$, $f(1) = 1$, $f(2) = 4$이므로 치역은 $\{0,\,1,\,4\}$다. 공역 $Y$와 다르다는 점에 주의한다. $-1 \ne 1$인데 $f(-1) = f(1) = 1$이므로 일대일함수가 아니고, 따라서 역함수도 존재하지 않는다.

**예제 2 (교과서 수준).** $f(x) = 2x + 1$, $g(x) = x^{2} - 3$일 때 $(f \circ g)(x)$, $(g \circ f)(x)$, $f^{-1}(x)$를 구하시오.

$(f \circ g)(x) = f(g(x)) = 2(x^{2} - 3) + 1 = 2x^{2} - 5$.
$(g \circ f)(x) = g(f(x)) = (2x + 1)^{2} - 3 = 4x^{2} + 4x - 2$.

확인: $x = 1$일 때 $g(1) = -2$, $f(-2) = -3$이고 식으로도 $2 - 5 = -3$이다. $f(1) = 3$, $g(3) = 6$이고 식으로도 $4 + 4 - 2 = 6$이다. 두 결과가 달라 $f \circ g \ne g \circ f$임을 볼 수 있다.

역함수: $y = 2x + 1$을 $x$에 대하여 풀면 $x = \dfrac{y - 1}{2}$, $x$와 $y$를 바꾸면 $f^{-1}(x) = \dfrac{x - 1}{2}$. 확인: $f(3) = 7$이고 $f^{-1}(7) = \dfrac{7 - 1}{2} = 3$이다.

**예제 3 (심화).** 실수 전체의 집합에서 정의된 함수
$$f(x) = \begin{cases} x + 3 & (x < 1) \\ 2x + a & (x \ge 1) \end{cases}$$
가 일대일대응일 때, 상수 $a$의 값과 $(f^{-1} \circ f^{-1})(4)$의 값을 구하시오.

두 부분이 모두 증가하는 직선이다. $x < 1$에서 치역은 $\{y \mid y < 4\}$, $x \ge 1$에서 치역은 $\{y \mid y \ge 2 + a\}$다. 실수 전체가 빠짐없이, 겹치지 않게 채워지려면 $2 + a = 4$, 즉 $a = 2$이다. ($2 + a < 4$이면 값이 겹쳐 일대일이 아니고, $2 + a > 4$이면 빈 구간이 생긴다.)

$f^{-1}(4) = k$라 하면 $f(k) = 4$다. $4 \ge 4$이므로 $k \ge 1$인 쪽에서 $2k + 2 = 4$, $k = 1$. 다음으로 $f^{-1}(1) = m$이면 $f(m) = 1 < 4$이므로 $m < 1$인 쪽에서 $m + 3 = 1$, $m = -2$. 따라서 $(f^{-1} \circ f^{-1})(4) = f^{-1}(f^{-1}(4)) = f^{-1}(1) = -2$.

확인: 거꾸로 $f(-2) = 1$, $f(1) = 2 + 2 = 4$이므로 $f(f(-2)) = 4$가 맞다.

## 자주 하는 실수와 오개념

**실수 1. 합성함수의 순서를 거꾸로 계산한다.**
왜 틀리는가: $(f \circ g)(x)$를 "$f$ 먼저, 그다음 $g$"로 읽어 $g(f(x))$를 계산한다. 기호를 왼쪽부터 읽는 습관 때문이다.
어떻게 바로잡는가: $(f \circ g)(x) = f(g(x))$로 **항상 괄호 꼴로 바꿔 쓴 뒤** 계산한다. $x$에 가까운 함수(안쪽, 오른쪽)가 먼저 작용한다. 예제 2처럼 $x = 1$을 넣어 두 방법을 비교하면 순서가 맞는지 바로 확인된다.

**실수 2. 치역과 공역을 같은 것으로 쓴다.**
왜 틀리는가: 예제 1에서 치역을 $Y = \{0,\,1,\,2,\,3,\,4\}$라고 쓴다. 공역은 "값이 놓일 수 있는 집합"이고, 치역은 "실제로 나온 값의 집합"이다.
어떻게 바로잡는가: 정의역의 원소를 하나씩 넣어 나온 값만 모아 치역을 만든다. 일대일대응 판정에서 "치역 $=$ 공역" 조건을 따로 확인하는 이유도 이 차이 때문이다.

**실수 3. $f^{-1}(x)$를 $\dfrac{1}{f(x)}$로 생각한다.**
왜 틀리는가: 지수 $-1$을 거듭제곱의 역수로 읽었다. $f(x) = 2x + 1$이면 $f^{-1}(x) = \dfrac{x - 1}{2}$이지 $\dfrac{1}{2x + 1}$이 아니다.
어떻게 바로잡는가: $f^{-1}$은 "$f$가 한 일을 되돌리는 함수"라는 뜻의 기호다. 구한 역함수가 맞는지 $f^{-1}(f(a)) = a$를 숫자 하나로 확인한다. 역함수를 구할 때 정의역(원래 함수의 치역)을 함께 적지 않으면 감점되는 경우도 많다.

**실수 4. $f(x) = f^{-1}(x)$의 해를 언제나 $f(x) = x$로 구한다.**
왜 틀리는가: 두 그래프가 $y = x$에 대칭이라서 교점도 항상 $y = x$ 위에 있다고 생각한다. 하지만 $f(x) = -x$는 $f^{-1}(x) = -x$로 자기 자신이 역함수이므로 모든 점에서 만나는데, $f(x) = x$의 해는 $x = 0$ 하나뿐이다.
어떻게 바로잡는가: $f$가 **증가함수**일 때만 $y = f(x)$와 $y = f^{-1}(x)$의 교점이 $y = x$ 위에 있다는 사실을 쓸 수 있다. 감소하는 부분이 있으면 $y = x$ 밖의 교점이 있는지 따로 확인한다.

## 앞뒤 학년 연계

중학교에서 "$x$의 값이 정해지면 $y$의 값이 하나 정해지는 관계"로 배운 함수를 집합 사이의 대응으로 다시 정의한다. 함수의 개수는 공통수학1의 순열과 연결된다. 다음 단원 유리함수와 무리함수에서는 평행이동과 역함수를 이용해 새로운 그래프를 그리고, 이후 지수함수와 로그함수가 서로 역함수 관계라는 점으로 이어진다.
