## 핵심 개념

> **한 줄 요약.** 0을 기준으로 반대 방향의 양을 나타내려고 음수를 만들었고, 수직선 위의 "이동"으로 생각하면 부호가 있는 수의 계산 규칙이 모두 설명된다.

지금까지는 $0$에서 오른쪽으로만 수를 늘어놓았다면, 이제 $0$의 왼쪽에도 수가 생긴다. 양수는 "앞으로", 음수는 "뒤로"이고, 덧셈은 그 방향대로 걸어가는 것이다.

**생활 속에서.** 영하 $5^\circ\text{C}$, 지하 $2$층, 통장의 $-3000$원(출금), 해발 $-400\,\text{m}$인 사해 수면, 경기의 득실차 $-2$처럼 기준보다 "모자라거나 반대쪽"인 양은 모두 음수로 나타낸다. 기온이 $-3^\circ\text{C}$에서 $5^\circ\text{C}$ 오르면 몇 도인지, 엘리베이터가 $3$층에서 $5$층 내려가면 몇 층인지를 계산하는 것이 바로 정수의 덧셈·뺄셈이다.

$0$보다 큰 수를 **양수**, $0$보다 작은 수를 **음수**라고 하고, 음수에는 부호 $-$를 붙여 $-3$, $-\dfrac{1}{2}$처럼 쓴다. 양수에는 $+$를 붙이거나 생략한다. $0$은 양수도 음수도 아니다.

자연수에 부호 $+$를 붙인 **양의 정수**(자연수), $0$, 자연수에 부호 $-$를 붙인 **음의 정수**를 합쳐 **정수**라고 한다. 정수 $a$와 $0$이 아닌 정수 $b$로 $\dfrac{a}{b}$ 꼴로 나타낼 수 있는 수를 **유리수**라고 한다. $-3 = \dfrac{-3}{1}$, $0.7 = \dfrac{7}{10}$이므로 정수와 소수도 유리수다.

**수직선**은 직선 위에 기준점 $0$(원점)을 잡고 오른쪽에 양수, 왼쪽에 음수를 같은 간격으로 늘어놓은 것이다. 수직선에서 오른쪽에 있는 수가 더 크다. 그래서 $-5 < -2 < 0 < 3$이다.

```numberline

range: [-6, 4]
draw:
  - point: -5
    label: "−5"
  - point: -2
    label: "−2"
  - point: 0
    label: "0 (원점)"
  - point: 3
    label: "3"
```

**절댓값**은 수직선 위에서 어떤 수와 원점 사이의 거리다. $|3| = 3$, $|-3| = 3$, $|0| = 0$이고, 거리이므로 절댓값은 항상 $0$ 이상이다. 음수끼리 비교할 때는 절댓값이 큰 쪽이 원점에서 더 멀리 왼쪽에 있으므로 더 작다.

```numberline

draw:

    label: "거리 3"
  - jump: [0, 3]
    label: "거리 3"
  - point: -3
  - point: 3
```

## 공식·정리

**덧셈·뺄셈** (모든 유리수에서 성립)

- 부호가 같은 두 수의 합: 절댓값의 합에 **공통 부호**를 붙인다. $(-3) + (-4) = -7$
- 부호가 다른 두 수의 합: 절댓값의 차에 **절댓값이 큰 쪽의 부호**를 붙인다. $(-7) + 4 = -3$. 절댓값이 같으면 합은 $0$이다.
- 뺄셈은 빼는 수의 부호를 바꾸어 더한다. $a - b = a + (-b)$, $a - (-b) = a + b$
- 덧셈에서는 교환법칙 $a + b = b + a$, 결합법칙 $(a + b) + c = a + (b + c)$가 성립한다. **뺄셈에서는 성립하지 않는다**($5 - 2 \ne 2 - 5$).

**곱셈·나눗셈**

- 부호가 같은 두 수의 곱·몫은 $+$, 부호가 다른 두 수의 곱·몫은 $-$. 크기는 절댓값끼리 곱하거나 나눈다.
- 여러 수의 곱: $0$이 하나라도 있으면 $0$이고, $0$이 없을 때 음수가 **짝수 개**면 $+$, **홀수 개**면 $-$.
- 나눗셈은 역수의 곱셈으로 바꾼다. $a \div b = a \times \dfrac{1}{b}$ ($b \ne 0$). $0$의 역수는 없고, **어떤 수도 $0$으로 나눌 수 없다.**
- 거듭제곱의 부호: $(-a)^{\text{짝수}}$는 양수, $(-a)^{\text{홀수}}$는 음수 ($a > 0$일 때). **$-a^{2}$은 $a^{2}$에 $-$를 붙인 것**이므로 $(-a)^{2}$과 다르다.
- 분배법칙 $a \times (b + c) = a \times b + a \times c$가 성립한다.

**계산 순서**: 거듭제곱 → 괄호 안(소괄호 → 중괄호 → 대괄호) → 곱셈·나눗셈(왼쪽부터) → 덧셈·뺄셈(왼쪽부터).

## 왜 성립하는가

**부호가 다른 수의 덧셈.** $(-7) + 4$는 원점에서 왼쪽으로 $7$칸 간 뒤 오른쪽으로 $4$칸 돌아오는 것이다. 왼쪽으로 간 거리가 더 크므로 결과는 왼쪽(음수)에 있고, 그 거리는 $7 - 4 = 3$이다.

```numberline
title: (−7) + 4 = −3. −7 에서 출발해 오른쪽으로 4칸 가면 −3 에 도착한다
range: [-8, 2]
draw:
  - point: -7
    color: base
  - jump: [-7, -3]
    label: "+4"
  - point: -3
```

**뺄셈을 덧셈으로 바꾸는 이유.** 수직선에서 "$+3$"은 오른쪽으로 $3$칸, "$-3$"은 왼쪽으로 $3$칸 이동이다. "$-(-3)$"은 왼쪽 $3$칸의 반대, 즉 오른쪽 $3$칸이므로 $+3$을 더하는 것과 같다. 그래서 $5 - (-3) = 5 + 3 = 8$이다. 거꾸로 생각해도 된다. $5 - (-3)$은 "$-3$에서 $5$까지 몇 칸인가"이므로 수직선에서 세어 보면 $8$칸이다.

**음수 $\times$ 음수가 왜 양수인가 (규칙의 일관성).** 곱하는 수를 $1$씩 줄이면서 패턴을 본다.

$$
\begin{aligned}
3 \times (-2) &= -6 \\
2 \times (-2) &= -4 \\
1 \times (-2) &= -2 \\
0 \times (-2) &= 0 \\
(-1) \times (-2) &= 2 \\
(-2) \times (-2) &= 4
\end{aligned}
$$

앞의 수가 $1$ 줄 때마다 결과가 $2$씩 커진다. 이 규칙이 $0$을 지나서도 계속되려면 $(-1) \times (-2) = 2$, $(-2) \times (-2) = 4$여야 한다.

같은 결론을 분배법칙으로도 확인할 수 있다. $3 + (-3) = 0$이므로 $(-2) \times \{3 + (-3)\} = (-2) \times 0 = 0$이다. 분배법칙을 쓰면

$$(-2) \times 3 + (-2) \times (-3) = -6 + (-2) \times (-3) = 0$$

이므로 $(-2) \times (-3) = 6$이어야 한다. 즉 음수 $\times$ 음수를 양수로 정해야 지금까지 쓰던 계산 규칙이 전부 그대로 유지된다.

## 대표 예제

**예제 1 (기본).** 다음을 계산하시오. (1) $(-7) + 4$ (2) $(-3) - (-8)$ (3) $2 - 9$

풀이 전략: 뺄셈은 먼저 "빼는 수의 부호를 바꿔 더하기"로 고친 뒤, 덧셈 규칙을 쓴다.

(1) 부호가 다르므로 절댓값의 차 $7 - 4 = 3$에 절댓값이 큰 $-7$의 부호를 붙여 $-3$.

(2) $(-3) - (-8) = (-3) + 8$. 부호가 다르고 절댓값의 차는 $8 - 3 = 5$, 큰 쪽 $8$의 부호 $+$이므로 $5$.

(3) $2 - 9 = 2 + (-9)$. 절댓값의 차 $9 - 2 = 7$, 큰 쪽 $-9$의 부호를 붙여 $-7$.

**예제 2 (기본).** 다음을 계산하시오. (1) $(-2)^{3} \times (-3) \div 6$ (2) $-2^{2} + (-2)^{2}$

풀이 전략: 거듭제곱을 먼저 계산하고, 괄호가 밑에 붙어 있는지 확인한다.

(1) $(-2)^{3} = (-2) \times (-2) \times (-2) = -8$. $(-8) \times (-3) = 24$ (음수 2개 → $+$). $24 \div 6 = 4$.

(2) $-2^{2} = -(2 \times 2) = -4$, $(-2)^{2} = (-2) \times (-2) = 4$. 따라서 $-4 + 4 = 0$.

**예제 3 (표준).** 수직선에서 $-\dfrac{7}{3}$과 $\dfrac{5}{2}$ 사이에 있는 정수를 모두 구하시오.

풀이 전략: 분수를 대분수(또는 소수)로 바꿔 어느 정수 사이에 있는지 보고, 수직선에 표시해 센다.

1. $-\dfrac{7}{3} = -2\dfrac{1}{3}$이므로 $-3$과 $-2$ 사이에 있다.
2. $\dfrac{5}{2} = 2\dfrac{1}{2}$이므로 $2$와 $3$ 사이에 있다.
3. 그 사이의 정수는 $-2,\ -1,\ 0,\ 1,\ 2$로 $5$개.

```numberline
title: −7/3(= −2와 1/3)과 5/2(= 2와 1/2) 사이의 정수는 −2, −1, 0, 1, 2 의 5개
range: [-4, 4]
draw:
  - point: -2.3333
    open: true
    label: "−7/3"
  - point: 2.5
    open: true
    label: "5/2"
  - point: -2
  - point: -1
  - point: 0
  - point: 1
  - point: 2
```

**예제 4 (응용).** 어느 날 새벽 기온이 $-4^\circ\text{C}$였다. 낮까지 $7^\circ\text{C}$ 올랐다가 밤까지 다시 $9^\circ\text{C}$ 내려갔다. 밤 기온은 몇 도이고, 하루 중 가장 높은 기온과 밤 기온의 차는 얼마인가?

풀이 전략: 오른 것은 $+$, 내린 것은 $-$로 두고 차례로 더한다. 두 기온의 차는 (큰 값) $-$ (작은 값)이다.

1. 낮 기온: $(-4) + 7 = 3$, 즉 $3^\circ\text{C}$.
2. 밤 기온: $3 + (-9) = -6$, 즉 $-6^\circ\text{C}$.
3. 기온 차: $3 - (-6) = 3 + 6 = 9$, 즉 $9^\circ\text{C}$. (내려간 만큼과 같다.)

**예제 5 (심화).** (1) $3 - \{(-2)^{2} \times (-3) + 15 \div (-5)\}$를 계산하시오. (2) $|a| = 3$, $|b| = 5$일 때 $a - b$의 값 중 가장 큰 것을 구하시오.

풀이 전략: (1)은 거듭제곱 → 괄호 안 곱셈·나눗셈 → 괄호 안 덧셈 → 바깥 순서. (2)는 절댓값이 같은 수가 두 개씩 있으므로 경우를 나눈다.

(1) 거듭제곱부터: $(-2)^{2} = 4$. 중괄호 안의 곱셈·나눗셈: $4 \times (-3) = -12$, $15 \div (-5) = -3$. 중괄호 안의 합: $(-12) + (-3) = -15$. 마지막으로 $3 - (-15) = 3 + 15 = 18$.

(2) $a$는 $3$ 또는 $-3$, $b$는 $5$ 또는 $-5$다. $a - b$가 가장 크려면 $a$는 최대, $b$는 최소여야 하므로 $a = 3$, $b = -5$. 이때 $a - b = 3 - (-5) = 8$. (나머지 경우 $3 - 5 = -2$, $-3 - (-5) = 2$, $-3 - 5 = -8$로 모두 $8$보다 작다.)

### 스스로 확인

1. $(-12) \div (-3) \times (-2)$를 계산하시오.
2. $-2^{4} - (-2)^{3}$을 계산하시오.
3. 절댓값이 $3$ 이하인 정수는 모두 몇 개인가?

<details>
<summary>정답과 풀이</summary>

1. 왼쪽부터 계산한다. $(-12) \div (-3) = 4$, $4 \times (-2) = -8$.
2. $-2^{4} = -16$, $(-2)^{3} = -8$이므로 $-16 - (-8) = -16 + 8 = -8$.

## 자주 하는 실수와 오개념

**실수 1. $-3^{2}$을 $9$라고 쓴다.**

- **왜 틀리는가:** $-3^{2}$과 $(-3)^{2}$을 같은 것으로 본다. 제곱되는 것은 $3$뿐이고 $-$는 밖에 남아 있다.
- **어떻게 바로잡는가:** 괄호가 없으면 거듭제곱이 먼저이므로 $-3^{2} = -(3 \times 3) = -9$, 괄호가 있으면 $(-3)^{2} = (-3) \times (-3) = 9$라고 두 식을 나란히 써서 비교하게 한다. 시험에서 가장 자주 감점되는 지점이다.

**실수 2. $(-3) - (-5)$에서 부호를 하나만 바꾼다.**

- **왜 틀리는가:** $-(-5)$를 $-5$로 두고 $(-3) + (-5) = -8$로 계산한다.
- **어떻게 바로잡는가:** 뺄셈은 항상 "빼는 수의 부호를 바꿔 더한다"로 먼저 고쳐 쓰게 한다. $(-3) - (-5) = (-3) + 5 = 2$. 수직선에서 "$-5$만큼 빼기 = $5$만큼 오른쪽"으로 확인시킨다.

**실수 3. 음수끼리 더하면 양수라고 한다.**

- **왜 틀리는가:** 곱셈의 "음수 $\times$ 음수 $= $ 양수" 규칙을 덧셈에 그대로 가져온다.
- **어떻게 바로잡는가:** 덧셈은 "이동", 곱셈은 "부호 규칙"으로 구분한다. $(-3) + (-4)$는 왼쪽으로 $3$칸 가고 또 왼쪽으로 $4$칸 가는 것이므로 $-7$이다. "빚 $3$만 원에 빚 $4$만 원이 더해지면 빚 $7$만 원"처럼 상황으로 확인한다.

**실수 4. $-5 > -2$라고 한다.**

- **왜 틀리는가:** 절댓값이 큰 $5$가 $2$보다 크다는 자연수 감각을 음수에 그대로 적용한다.
- **어떻게 바로잡는가:** 수직선을 그려 $-5$가 $-2$보다 왼쪽에 있음을 보게 한다. 영하 $5$도가 영하 $2$도보다 더 춥다(더 낮다)는 것과 연결하면 "음수는 절댓값이 클수록 작다"가 기억된다.

**실수 5. $-\dfrac{1}{2}$과 $-\dfrac{1}{3}$ 중 $-\dfrac{1}{3}$이 더 작다고 한다.**

- **왜 틀리는가:** 양수 $\dfrac{1}{2} > \dfrac{1}{3}$을 떠올린 뒤 "음수는 반대"를 한 번 더 뒤집거나, 분모가 큰 쪽이 작다는 것만 기억한다.
- **어떻게 바로잡는가:** 먼저 절댓값을 비교하고($\dfrac{1}{2} > \dfrac{1}{3}$), 음수에서는 절댓값이 큰 쪽이 작다는 한 단계만 쓰게 한다. 따라서 $-\dfrac{1}{2} < -\dfrac{1}{3}$. 통분해 $-\dfrac{3}{6} < -\dfrac{2}{6}$로 확인한다.
