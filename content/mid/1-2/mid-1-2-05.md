## 핵심 개념

조사한 자료의 각 값을 **변량**이라고 한다. **줄기와 잎 그림**은 변량을 십의 자리(줄기)와 일의 자리(잎)로 나누어 정리한 그림으로, 원래 값을 하나도 잃지 않으면서 자료가 어디에 몰려 있는지 한눈에 보여 준다. 잎은 작은 수부터 크기순으로 쓰고, 같은 값이 여러 개면 여러 번 쓴다.

자료를 일정한 구간으로 나눈 것이 **계급**, 구간의 너비가 **계급의 크기**, 각 계급의 가운데 값이 **계급값**, 각 계급에 속하는 변량의 개수가 **도수**다. 계급과 도수를 표로 정리한 것이 **도수분포표**이며, 자료가 많을 때 분포를 파악하기 좋지만 개별 값은 알 수 없다.

**히스토그램**은 도수분포표를 그래프로 나타낸 것이다. 가로축에 계급, 세로축에 도수를 두고, 계급의 크기를 가로, 도수를 세로로 하는 직사각형을 **서로 붙여서** 그린다. 가로축이 이어진 수의 범위이기 때문에 막대 사이에 틈이 없다.

**도수분포다각형**은 히스토그램의 각 직사각형 윗변의 가운데 점을 선분으로 이은 그래프다. 양 끝에는 도수가 $0$인 계급을 하나씩 더 있다고 보고 가로축 위의 점까지 잇는다. 여러 집단을 한 그림에 겹쳐 그려 비교하기 쉽다.

**상대도수**는 전체 도수에 대한 각 계급의 도수의 비율이다. 전체 인원이 다른 두 집단(예: 20명인 반과 50명인 반)을 비교할 때 도수 대신 상대도수를 쓴다.

## 공식·정리

- **계급값** $= \dfrac{(\text{계급의 양 끝값의 합})}{2}$. 예를 들어 "$60$ 이상 $70$ 미만"의 계급값은 $65$.
- 계급은 "$a$ 이상 $b$ 미만"으로 쓴다. 경계값 $b$는 **다음 계급**에 들어간다.
- **상대도수** $= \dfrac{(\text{그 계급의 도수})}{(\text{전체 도수})}$. 각 상대도수는 $0$ 이상 $1$ 이하이고, **상대도수의 총합은 항상 $1$** 이다.
- 거꾸로 $(\text{도수}) = (\text{상대도수}) \times (\text{전체 도수})$, $(\text{전체 도수}) = \dfrac{(\text{어떤 계급의 도수})}{(\text{그 계급의 상대도수})}$.
- **히스토그램**에서 각 직사각형의 넓이 $= (\text{계급의 크기}) \times (\text{도수})$이므로 넓이는 도수에 정비례하고, 직사각형 넓이의 합 $= (\text{계급의 크기}) \times (\text{전체 도수})$.
- **도수분포다각형**과 가로축으로 둘러싸인 넓이는 히스토그램의 직사각형 넓이의 합과 같다.

## 왜 성립하는가

**상대도수의 합이 $1$인 이유.** 전체 도수를 $N$, 각 계급의 도수를 $f_1, f_2, \dots, f_k$라 하면 $f_1 + f_2 + \dots + f_k = N$이다. 상대도수를 모두 더하면

$$\frac{f_1}{N} + \frac{f_2}{N} + \dots + \frac{f_k}{N} = \frac{f_1 + f_2 + \dots + f_k}{N} = \frac{N}{N} = 1$$
이다. 백분율로 나타내면 합이 $100\,\%$가 된다.

**도수분포다각형의 넓이가 히스토그램의 넓이와 같은 이유.** 이웃한 두 직사각형의 윗변 가운데 점을 이으면, 선분 위쪽으로 잘려 나가는 작은 삼각형과 선분 아래쪽으로 새로 더해지는 작은 삼각형이 생긴다. 두 삼각형은 밑변(계급의 크기의 절반)과 높이(두 도수의 차)가 같아 합동이므로 넓이가 같다. 모든 경계에서 잘린 만큼 더해지므로 전체 넓이는 변하지 않는다.

**히스토그램 막대의 넓이가 도수에 비례하는 이유.** 모든 직사각형의 가로 길이가 계급의 크기로 똑같으므로, 넓이는 세로 길이인 도수에만 따라 결정된다. 그래서 히스토그램은 "높이"뿐 아니라 "넓이"로도 도수를 읽을 수 있다.

## 대표 예제

**예제 1 (교과서 수준).** 어느 반 학생 $12$명의 수학 점수가 다음과 같다. 줄기와 잎 그림으로 나타내고, $80$점 이상인 학생 수를 구하시오.
$$73,\ 85,\ 62,\ 91,\ 78,\ 84,\ 73,\ 95,\ 80,\ 65,\ 89,\ 71$$

줄기를 십의 자리, 잎을 일의 자리로 두고 잎을 크기순으로 쓴다.

| 줄기 | 잎 |
| --- | --- |
| 6 | 2 5 |
| 7 | 1 3 3 8 |
| 8 | 0 4 5 9 |
| 9 | 1 5 |

$80$점 이상은 줄기 $8$과 $9$의 잎을 세면 $4 + 2 = 6$명. (확인: 잎의 총 개수 $2 + 4 + 4 + 2 = 12$로 자료 수와 같고, 원자료에서 $80$ 이상인 값을 직접 세면 $85, 91, 84, 95, 80, 89$의 $6$개다.)

**예제 2 (교과서 수준).** 학생 $40$명의 하루 공부 시간을 조사한 도수분포표의 빈칸(상대도수)을 채우고, $2$시간 이상 공부한 학생의 비율을 구하시오.

| 공부 시간(시간) | 도수(명) | 상대도수 |
| --- | --- | --- |
| $0$ 이상 $1$ 미만 | $4$ | |
| $1$ 이상 $2$ 미만 | $10$ | |
| $2$ 이상 $3$ 미만 | $14$ | |
| $3$ 이상 $4$ 미만 | $8$ | |
| $4$ 이상 $5$ 미만 | $4$ | |
| 합계 | $40$ | |

상대도수는 각 도수를 $40$으로 나눈다. $\dfrac{4}{40} = 0.1$, $\dfrac{10}{40} = 0.25$, $\dfrac{14}{40} = 0.35$, $\dfrac{8}{40} = 0.2$, $\dfrac{4}{40} = 0.1$. (확인: $0.1 + 0.25 + 0.35 + 0.2 + 0.1 = 1$.)
$2$시간 이상은 세 번째 계급부터이므로 $0.35 + 0.2 + 0.1 = 0.65$, 즉 $65\,\%$. (확인: 도수로 세면 $14 + 8 + 4 = 26$명이고 $\dfrac{26}{40} = 0.65$.)

**예제 3 (심화).** 어느 학교 $1$학년 A반과 B반의 통학 시간을 조사했다. A반은 전체 $20$명 중 "$30$분 이상 $40$분 미만" 계급의 도수가 $5$명이고, B반은 같은 계급의 도수가 $9$명이며 상대도수가 $0.18$이다.
(1) B반 전체 학생 수를 구하시오. (2) 이 계급의 학생 비율은 어느 반이 더 높은지 상대도수로 비교하시오. (3) B반에서 "$40$분 이상 $50$분 미만" 계급의 상대도수가 $0.3$일 때 그 계급의 도수를 구하시오.

(1) $(\text{전체 도수}) = \dfrac{9}{0.18} = 50$명. (확인: $50 \times 0.18 = 9$.)
(2) A반의 상대도수는 $\dfrac{5}{20} = 0.25$, B반은 $0.18$이다. 도수는 B반($9$명)이 더 많지만 **비율은 A반이 더 높다.** (확인: A반 $25\,\%$, B반 $18\,\%$.)
(3) $(\text{도수}) = 0.3 \times 50 = 15$명. (확인: $\dfrac{15}{50} = 0.3$.)

## 자주 하는 실수와 오개념

**실수 1. 히스토그램을 막대그래프처럼 막대 사이를 띄워 그리거나, 둘을 같은 것으로 생각한다.**

- **왜 틀리는가:** 초등학교에서 배운 막대그래프와 겉모습이 비슷해 구분하지 않는다.
- **어떻게 바로잡는가:** 막대그래프는 가로축이 "혈액형, 좋아하는 과목"처럼 따로따로인 항목이라 막대를 띄우고, 히스토그램은 가로축이 "$60$ 이상 $70$ 미만"처럼 **이어진 수의 범위**라 붙인다는 차이를 가로축을 보고 판단하게 한다.

**실수 2. 상대도수의 합이 $1$이 아닌데 그대로 둔다.**

- **왜 틀리는가:** 분모에 전체 도수가 아니라 다른 계급의 도수나 계급의 개수를 넣거나, 나눗셈을 틀려도 검산하지 않는다.
- **어떻게 바로잡는가:** 상대도수 표를 완성하면 반드시 세로로 더해 $1$(백분율이면 $100\,\%$)이 되는지 확인한다. 안 맞으면 분모가 전체 도수인지부터 점검한다.

**실수 3. 경계값을 어느 계급에 넣을지 헷갈린다.**

- **왜 틀리는가:** "$60$ 이상 $70$ 미만"에서 $70$이 이 계급에 들어가는지 다음 계급에 들어가는지 매번 고민하다 잘못 센다.
- **어떻게 바로잡는가:** "이상"은 포함, "미만"은 불포함이므로 경계값은 항상 **큰 쪽 계급**(다음 계급)에 들어간다고 정리한다. 변량 $70$은 "$70$ 이상 $80$ 미만"에 들어간다.

**실수 4. 전체 인원이 다른 두 집단을 도수로 직접 비교한다.**

- **왜 틀리는가:** "$9$명이 $5$명보다 많으니 B반이 더 많다"처럼 전체 인원 차이를 무시한다.
- **어떻게 바로잡는가:** 전체 도수가 다르면 반드시 상대도수로 바꿔 비교하게 한다. 위 예제처럼 도수는 더 많아도 비율은 더 낮을 수 있다는 것을 직접 계산해 보여 준다.

## 앞뒤 학년 연계

초등학교의 막대그래프·꺾은선그래프와 비율·백분율이 바탕이 되고, 여기서 배운 도수분포표와 상대도수는 중2 확률에서 "상대도수가 가까워지는 값"으로 확률을 이해하는 데 쓰인다. 중3에서는 자료를 평균·중앙값·최빈값으로 요약하는 대푯값과 산포도, 상자그림과 산점도로 이어진다.
