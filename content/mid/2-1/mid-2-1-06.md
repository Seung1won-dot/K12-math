## 핵심 개념

> **한 줄 요약.** 일차방정식 $ax + by + c = 0$의 그래프는 직선이고, 연립방정식의 해는 두 직선이 만나는 점의 좌표다. 만나지 않으면(평행) 해가 없고, 겹치면(일치) 해가 무수히 많다.

미지수가 $2$개인 일차방정식 $ax + by + c = 0$의 해 $(x,\,y)$를 좌표평면에 모두 찍으면 **직선**이 된다. 이 직선을 **일차방정식의 그래프**라고 한다. $b \ne 0$이면 식을 $y = -\dfrac{a}{b}x - \dfrac{c}{b}$로 고칠 수 있으므로 일차함수의 그래프와 같은 직선이다. 즉 일차방정식과 일차함수는 같은 직선을 다른 꼴의 식으로 쓴 것이다.

$a = 0$이거나 $b = 0$인 경우는 따로 본다. $y = k$의 그래프는 $x$축에 평행한 직선이고, $x = k$의 그래프는 $y$축에 평행한 직선이다. $x = k$는 $x$ 하나에 $y$가 무수히 많이 대응하므로 **함수는 아니지만** 그래프는 그릴 수 있다.

연립방정식 $\begin{cases} ax + by + c = 0 \\ a'x + b'y + c' = 0 \end{cases}$의 해는 두 직선의 **교점의 좌표**와 같다. 두 직선이 한 점에서 만나면 해가 하나, 평행하면 해가 없고, 일치하면 해가 무수히 많다.

예를 들어 직선 $x + y = 5$는 점 $(0,\,5)$, $(5,\,0)$을 지나고, 직선 $x - y = 1$은 점 $(0,\,-1)$, $(1,\,0)$을 지난다. 두 직선은 점 $(3,\,2)$에서 만나며, 이 점이 연립방정식 $\begin{cases} x + y = 5 \\ x - y = 1 \end{cases}$의 해다.

```plot

y: [-3, 7]
draw:

    label: x + y = 5
    labelAt: 0.6
    pos: e
  - fn: x - 1
    color: base
    label: x − y = 1
    labelAt: 5.6
    pos: e
  - point: [3, 2]

    guide: true

```

**생활 속에서.** 휴대전화 요금제 두 가지, 택시와 버스의 요금처럼 "어느 쪽이 더 싼가"를 비교할 때 두 요금을 각각 일차식으로 쓰고 그래프로 그리면 교점이 "두 요금이 같아지는 순간"이다. 교점 왼쪽과 오른쪽에서 어느 직선이 아래에 있는지 보면 언제 무엇을 고르는 것이 유리한지 한눈에 판단할 수 있다.

## 공식·정리

**일차방정식의 그래프.** $a$, $b$, $c$가 상수일 때

- $a \ne 0$, $b \ne 0$: $ax + by + c = 0 \iff y = -\dfrac{a}{b}x - \dfrac{c}{b}$. 기울기 $-\dfrac{a}{b}$, $y$절편 $-\dfrac{c}{b}$인 직선.
- $a = 0$, $b \ne 0$: $y = -\dfrac{c}{b}$, 즉 $y = k$ 꼴. 점 $(0,\,k)$를 지나고 $x$축에 평행한 직선.
- $a \ne 0$, $b = 0$: $x = -\dfrac{c}{a}$, 즉 $x = k$ 꼴. 점 $(k,\,0)$을 지나고 $y$축에 평행한 직선.
- $a = b = 0$인 경우는 일차방정식이 아니다.

**연립방정식의 해와 두 직선의 위치 관계.** 두 식을 각각 $y = mx + n$, $y = m'x + n'$으로 고쳤을 때

| 두 직선 | 조건 | 연립방정식의 해 |
| --- | --- | --- |
| 한 점에서 만난다 | $m \ne m'$ | 한 쌍 (교점의 좌표) |
| 평행하다 | $m = m'$, $n \ne n'$ | 없다 |
| 일치한다 | $m = m'$, $n = n'$ | 무수히 많다 |

**교점 구하기.** 두 직선의 교점의 좌표는 두 방정식을 연립하여 풀어서 구한다.

## 왜 성립하는가

**$ax + by + c = 0$의 그래프가 직선인 이유.** $b \ne 0$이면 $by = -ax - c$이고 양변을 $b$로 나누면 $y = -\dfrac{a}{b}x - \dfrac{c}{b}$다. 이것은 일차함수이므로 그래프는 직선이다. 예를 들어 $2x - y + 4 = 0$은 $y = 2x + 4$와 같은 직선이다.

**$x = k$의 그래프가 $y$축에 평행한 이유.** $x = 3$을 만족하는 순서쌍은 $(3,\,0)$, $(3,\,1)$, $(3,\,-2)$, … 처럼 $x$좌표가 $3$이기만 하면 $y$는 아무 값이어도 된다. 이 점들을 모두 찍으면 $x$축 위의 $3$을 지나 위아래로 뻗은 직선이 된다. 마찬가지로 $y = 2$는 $y$좌표가 $2$인 모든 점이므로 가로로 뻗은 직선이다.

```plot
title: x = 3 은 x좌표가 3 인 점을 모은 세로선, y = 2 는 y좌표가 2 인 점을 모은 가로선
x: [-2, 6]
y: [-3, 5]
draw:
  - vline: 3
    dash: false
    color: accent
    width: 2.5
    label: x = 3
  - hline: 2
    dash: false
    width: 2.5
    label: y = 2
  - point: [3, 0]
    color: accent
  - point: [3, -2]
    color: accent
  - point: [3, 4]
    color: accent
  - point: [3, 2]
    color: base
    label: (3, 2)
    pos: ne
```

**교점이 연립방정식의 해인 이유.** 직선 위의 점은 그 방정식을 만족하는 점이다. 교점은 **두 직선 위에 동시에** 있으므로 두 방정식을 동시에 만족하고, 이것이 바로 연립방정식의 해의 정의다.

**평행이면 해가 없는 이유.** $y = 2x + 1$과 $y = 2x - 3$을 연립하면 $2x + 1 = 2x - 3$, 즉 $1 = -3$으로 모순이다. 기울기가 같아 $x$항이 사라지는데 $y$절편이 달라 남은 등식이 거짓이므로 해가 없고, 그래프로는 평행하여 만나지 않는다. $y$절편까지 같으면 $0 = 0$이 되어 두 직선이 일치하고 해는 무수히 많다.

```plot

x: [-3, 4]
y: [-5, 6]
draw:
  - fn: 2x + 1
    color: base
    label: y = 2x + 1
    labelAt: 2
    pos: w
  - fn: 2x - 3
    color: accent
    label: y = 2x − 3
    labelAt: 3
    pos: e
  - point: [0, 1]
    color: base
  - point: [0, -3]
    color: accent
```

## 대표 예제

**예제 1 (기본).** 일차방정식 $2x - y + 4 = 0$을 $y = ax + b$ 꼴로 고치고 기울기와 $y$절편을 구하시오. 또 $3y - 6 = 0$의 그래프를 설명하시오.

풀이 전략: $y$항만 좌변에 남기고 양변을 $y$의 계수로 나눈다. $x$가 없는 식은 $y = k$ 꼴이다.

1. $2x$와 $4$를 이항하면 $-y = -2x - 4$. 양변에 $-1$을 곱하면 $y = 2x + 4$.
2. 기울기 $2$, $y$절편 $4$. 확인: $x = -2$, $y = 0$을 원래 식에 넣으면 $-4 - 0 + 4 = 0$.
3. $3y - 6 = 0$은 $3y = 6$, $y = 2$이므로 점 $(0,\,2)$를 지나고 $x$축에 평행한 직선이다.

**예제 2 (기본).** 두 직선 $x + y = 5$, $x - y = 1$의 교점의 좌표를 구하시오.

풀이 전략: 교점의 좌표는 두 식을 연립해 푼 해다. $y$의 계수 부호가 반대이므로 더한다.

1. 두 식을 더하면 $2x = 6$, $x = 3$.
2. 첫 식에 넣으면 $3 + y = 5$, $y = 2$.
3. 교점은 $(3,\,2)$. 확인: $3 + 2 = 5$, $3 - 2 = 1$로 두 직선 위에 모두 있다(핵심 개념의 그림).

**예제 3 (표준).** 두 직선 $ax - y + 2 = 0$과 $2x - y - 1 = 0$이 평행할 때 상수 $a$의 값을 구하시오.

풀이 전략: 두 식을 $y = mx + n$ 꼴로 고치고 "기울기 같음, $y$절편 다름"을 확인한다.

1. 각각 $y = ax + 2$, $y = 2x - 1$.
2. 평행하려면 기울기가 같아야 하므로 $a = 2$.
3. $y$절편은 $2 \ne -1$로 다르므로 일치가 아니라 평행이다.
4. 확인: $a = 2$이면 $2x - y + 2 = 0$과 $2x - y - 1 = 0$을 빼서 $3 = 0$이 되어 해가 없다.

**예제 4 (응용).** 휴대전화 요금제 A는 기본료 $10000$원에 통화 $1$분마다 $100$원, 요금제 B는 기본료 $4000$원에 통화 $1$분마다 $200$원이다. 한 달 통화 시간이 몇 분보다 길 때 A가 더 싼가?

풀이 전략: 통화 시간 $x$분일 때 요금 $y$원을 각각 일차함수로 쓰고, 두 그래프의 교점을 구한다.

1. A: $y = 100x + 10000$, B: $y = 200x + 4000$.
2. 교점: $100x + 10000 = 200x + 4000$에서 $100x = 6000$, $x = 60$. 이때 $y = 6000 + 10000 = 16000$.
3. 교점 $(60,\,16000)$에서 두 요금이 같다. 기울기가 큰 B가 $60$분 이후로는 위에 있으므로, $60$분보다 길게 통화하면 A가 더 싸다.
4. 확인: $x = 80$이면 A는 $18000$원, B는 $20000$원으로 A가 싸다. $x = 30$이면 A는 $13000$원, B는 $10000$원으로 B가 싸다.

**예제 5 (심화).** 세 직선 $y = 2x - 1$, $y = -x + 5$, $y = kx + 1$이 한 점에서 만날 때 상수 $k$의 값을 구하시오.

풀이 전략: $k$가 없는 두 직선의 교점을 먼저 구하고, 세 번째 직선이 그 점을 지나게 한다.

1. $2x - 1 = -x + 5$에서 $3x = 6$, $x = 2$, $y = 3$. 교점은 $(2,\,3)$.
2. $y = kx + 1$이 $(2,\,3)$을 지나야 하므로 $3 = 2k + 1$, $k = 1$.
3. 확인: $y = x + 1$, $y = 2x - 1$, $y = -x + 5$에 $x = 2$를 넣으면 모두 $y = 3$이다.


### 스스로 확인

1. 일차방정식 $3x + 2y - 6 = 0$의 그래프의 기울기, $y$절편, $x$절편을 구하시오.
2. 두 직선 $2x - y = 3$, $x + y = 3$의 교점의 좌표를 구하시오.
3. 두 일차방정식 $ax + 2y = 4$, $3x + y = b$의 그래프가 일치할 때 상수 $a$, $b$의 값을 구하시오.

1. $2y = -3x + 6$, $y = -\dfrac{3}{2}x + 3$이므로 기울기 $-\dfrac{3}{2}$, $y$절편 $3$. $y = 0$이면 $3x = 6$이므로 $x$절편 $2$.

## 자주 하는 실수와 오개념

**실수 1. $y = \cdots$ 꼴로 고칠 때 부호를 틀린다.**

- **왜 틀리는가:** $2x - y + 4 = 0$에서 $y = -2x - 4$ 또는 $y = 2x - 4$로 쓴다. $-y$를 $y$로 바꾸면서 우변의 **모든 항**의 부호를 바꿔야 하는데 일부만 바꾼다.
- **어떻게 바로잡는가:** $-y = -2x - 4$까지 쓴 뒤 양변에 $-1$을 곱하는 줄을 따로 쓴다. 고친 식에 원래 식의 쉬운 해 하나(여기서는 $(0,\,4)$)를 넣어 성립하는지 확인한다.

**실수 2. $x = k$와 $y = k$의 방향을 바꿔 그린다.**

- **왜 틀리는가:** "$x = 3$"을 보고 $x$축 방향으로 뻗은 가로선을 그린다. 식에 $x$가 있으니 $x$축과 평행하다고 느낀다.
- **어떻게 바로잡는가:** 점을 세 개 찍어 본다. $(3,\,0)$, $(3,\,1)$, $(3,\,2)$가 세로로 늘어서므로 $x = 3$은 **세로선**($y$축에 평행)이다. "$x = k$는 $x$축 위의 $k$를 지나는 세로선, $y = k$는 $y$축 위의 $k$를 지나는 가로선"으로 정리한다.

**실수 3. $x = k$의 기울기를 구하려 한다.**

- **왜 틀리는가:** 모든 직선에 기울기가 있다고 생각해 $x = 3$을 $y = ax + b$ 꼴로 고치려 하거나 기울기를 $0$이라고 쓴다.
- **어떻게 바로잡는가:** 기울기는 $\dfrac{(y\text{의 증가량})}{(x\text{의 증가량})}$인데 $x = 3$ 위에서는 $x$의 증가량이 항상 $0$이어서 분모가 $0$이 된다. 따라서 기울기를 정할 수 없다. 기울기가 $0$인 직선은 $y = k$ 쪽이다.

**실수 4. 기울기만 같으면 무조건 "해가 없다"고 답한다.**

- **왜 틀리는가:** 평행 조건에서 $y$절편 비교를 빠뜨려, 사실은 일치하는 두 직선(해가 무수히 많음)을 평행으로 판정한다.
- **어떻게 바로잡는가:** 기울기가 같을 때는 반드시 $y$절편까지 비교하는 두 단계로 판정한다. 예를 들어 $2x + 4y = 6$과 $x + 2y = 3$은 기울기가 모두 $-\dfrac{1}{2}$이고 $y$절편도 $\dfrac{3}{2}$로 같아 **일치**한다.

**실수 5. 교점의 좌표를 그래프에서 눈대중으로 읽는다.**

- **왜 틀리는가:** 그래프를 그려 보면 교점이 바로 보이니 격자에서 가까운 정수 좌표를 답으로 쓴다. 하지만 $y = x$와 $y = -2x + 1$의 교점은 $\left(\dfrac{1}{3},\,\dfrac{1}{3}\right)$처럼 정수가 아닐 수 있다.
- **어떻게 바로잡는가:** 그래프는 교점이 "있는지, 대략 어디인지" 보는 데 쓰고, 정확한 좌표는 반드시 연립방정식을 풀어 구한다. $x = -2x + 1$에서 $3x = 1$, $x = \dfrac{1}{3}$처럼 계산으로 확정한다.
