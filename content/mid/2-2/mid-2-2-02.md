## 핵심 개념

> **한 줄 요약.** 평행사변형은 대변·대각이 같고 대각선이 서로 이등분하며, 여기에 조건이 하나씩 붙을 때마다 직사각형(대각선 길이 같음), 마름모(대각선 수직), 정사각형(둘 다)이 된다.

사각형의 이름은 "모양"이 아니라 "만족하는 조건"으로 정해진다. 그래서 정사각형은 직사각형이기도 하고 마름모이기도 하다. 이 단원은 각 사각형의 성질을 삼각형의 합동으로 증명하고, 어떤 조건을 더하면 어떤 사각형이 되는지를 정리한다.

**생활 속에서.** 엘리베이터의 접이식 문이나 늘였다 줄였다 하는 벽걸이 옷걸이는 마름모(평행사변형)가 이어진 구조라서 모양이 바뀌어도 마주 보는 막대가 계속 평행하다. 방문을 짤 때 목수가 두 대각선의 길이를 재어 같은지 확인하는 것은 "평행사변형에서 대각선의 길이가 같으면 직사각형"이라는 성질로 직각을 확인하는 방법이다.

**평행사변형**은 두 쌍의 대변이 각각 평행한 사각형이다. 사각형 $ABCD$에서 마주 보는 변($\overline{AB}$와 $\overline{DC}$, $\overline{AD}$와 $\overline{BC}$)을 **대변**, 마주 보는 각($\angle A$와 $\angle C$, $\angle B$와 $\angle D$)을 **대각**이라고 한다. 평행사변형에서는 두 쌍의 대변의 길이가 각각 같고, 두 쌍의 대각의 크기가 각각 같으며, 두 대각선이 서로 다른 것을 이등분한다.

거꾸로, 어떤 사각형이 이 성질 중 하나를 만족하면 그 사각형은 평행사변형이다. 이것을 **평행사변형이 되는 조건**이라고 하며, 모두 다섯 가지다.

**직사각형**은 네 내각의 크기가 모두 같은(모두 $90^\circ$인) 사각형, **마름모**는 네 변의 길이가 모두 같은 사각형, **정사각형**은 네 각의 크기와 네 변의 길이가 모두 같은 사각형이다. 셋 다 평행사변형의 성질을 모두 가지면서 대각선에 관한 성질이 하나씩 더 붙는다. 직사각형은 두 대각선의 길이가 같고, 마름모는 두 대각선이 서로 수직이며, 정사각형은 둘 다 성립한다.

**등변사다리꼴**은 한 쌍의 대변이 평행한 사다리꼴 중에서 평행한 한 변(아랫변)의 양 끝 각의 크기가 같은 사다리꼴이다. 평행하지 않은 두 변의 길이가 같고, 두 대각선의 길이가 같다.

## 공식·정리

**평행사변형 $ABCD$의 성질** (대각선의 교점을 $O$라 할 때)

- $\overline{AB} = \overline{DC}$, $\overline{AD} = \overline{BC}$.
- $\angle A = \angle C$, $\angle B = \angle D$. 이웃하는 두 각의 합은 $180^\circ$: $\angle A + \angle B = 180^\circ$.
- $\overline{OA} = \overline{OC}$, $\overline{OB} = \overline{OD}$.
- 조건: 위 성질은 **두 쌍의 대변이 모두 평행**할 때만 쓴다. 한 쌍만 평행한 사다리꼴에서는 성립하지 않는다.

**평행사변형이 되는 조건** (사각형 $ABCD$가 다음 중 하나를 만족하면 평행사변형)

1. 두 쌍의 대변이 각각 평행하다.
2. 두 쌍의 대변의 길이가 각각 같다.
3. 두 쌍의 대각의 크기가 각각 같다.
4. 두 대각선이 서로 다른 것을 이등분한다.
5. 한 쌍의 대변이 **평행하고 그 길이가 같다**. (조건: 평행한 변과 길이가 같은 변이 **같은 쌍**이어야 한다.)

**여러 가지 사각형의 대각선 성질**

| 사각형 | 서로 다른 것을 이등분 | 길이가 같다 | 서로 수직 |
| --- | --- | --- | --- |
| 평행사변형 | O | | |
| 직사각형 | O | O | |
| 마름모 | O | | O |
| 정사각형 | O | O | O |
| 등변사다리꼴 | | O | |

**평행사변형이 다른 사각형이 되는 조건**

- 평행사변형 + (한 내각이 $90^\circ$ 또는 두 대각선의 길이가 같다) $\Rightarrow$ 직사각형.
- 평행사변형 + (이웃하는 두 변의 길이가 같다 또는 두 대각선이 수직이다) $\Rightarrow$ 마름모.
- 직사각형의 조건과 마름모의 조건을 하나씩 모두 만족 $\Rightarrow$ 정사각형.
- 조건: 출발점이 **평행사변형**이어야 한다. 그냥 사각형에서 대각선의 길이만 같다고 직사각형이 되지는 않는다(등변사다리꼴이 반례).

## 왜 성립하는가

**평행사변형의 대변의 길이가 같은 이유.** 대각선 $\overline{AC}$를 그으면 $\triangle ABC$와 $\triangle CDA$에서, $\overline{AB} \parallel \overline{DC}$이므로 엇각 $\angle BAC = \angle DCA$, $\overline{AD} \parallel \overline{BC}$이므로 엇각 $\angle BCA = \angle DAC$, 그리고 $\overline{AC}$는 공통이다. ASA 합동이므로 $\overline{AB} = \overline{CD}$, $\overline{BC} = \overline{DA}$이고, 같은 합동에서 $\angle B = \angle D$도 얻는다.

**대각선이 서로 다른 것을 이등분하는 이유.** 교점을 $O$라 하면(위의 평행사변형 그림) $\triangle OAB$와 $\triangle OCD$에서 $\overline{AB} = \overline{CD}$(위에서 증명), $\angle OAB = \angle OCD$, $\angle OBA = \angle ODC$(각각 엇각)이므로 ASA 합동이다. 따라서 $\overline{OA} = \overline{OC}$, $\overline{OB} = \overline{OD}$.

**조건 5가 성립하는 이유.** $\overline{AB} \parallel \overline{DC}$, $\overline{AB} = \overline{DC}$라 하자. 대각선 $\overline{AC}$를 그으면 $\triangle ABC$와 $\triangle CDA$에서 $\overline{AB} = \overline{CD}$, 엇각 $\angle BAC = \angle DCA$, $\overline{AC}$ 공통이므로 SAS 합동이다. 따라서 $\angle BCA = \angle DAC$이고, 엇각이 같으므로 $\overline{AD} \parallel \overline{BC}$가 되어 두 쌍의 대변이 각각 평행하다.

**직사각형의 대각선 길이가 같은 이유.** $\triangle ABC$와 $\triangle DCB$에서 $\overline{AB} = \overline{DC}$, $\angle ABC = \angle DCB = 90^\circ$, $\overline{BC}$ 공통이므로 SAS 합동이다. 따라서 $\overline{AC} = \overline{DB}$.

**마름모의 대각선이 수직인 이유.** 대각선의 교점을 $O$라 하면 $\triangle ABO$와 $\triangle ADO$에서 $\overline{AB} = \overline{AD}$(네 변이 같음), $\overline{BO} = \overline{DO}$(평행사변형이므로 대각선이 이등분됨), $\overline{AO}$ 공통이므로 SSS 합동이다. 따라서 $\angle AOB = \angle AOD$이고 두 각의 합이 $180^\circ$이므로 각각 $90^\circ$이다.

**등변사다리꼴의 대각선 길이가 같은 이유.** $\overline{AD} \parallel \overline{BC}$, $\angle B = \angle C$인 등변사다리꼴 $ABCD$에서 $\overline{AB} = \overline{DC}$라는 사실(예제 5의 그림처럼 $\overline{DC}$에 평행한 보조선으로 증명)을 쓰면, $\triangle ABC$와 $\triangle DCB$는 $\overline{AB} = \overline{DC}$, $\angle ABC = \angle DCB$, $\overline{BC}$ 공통으로 SAS 합동이다. 따라서 $\overline{AC} = \overline{DB}$.

## 대표 예제

**예제 1 (기본).** 평행사변형 $ABCD$에서 $\angle A = 110^\circ$, $\overline{AB} = 7\,\text{cm}$, $\overline{BC} = 4\,\text{cm}$일 때 $\angle B$, $\overline{CD}$, 둘레의 길이를 구하시오.

풀이 전략: 이웃한 두 각의 합은 $180^\circ$, 대변의 길이는 같다는 성질을 차례로 쓴다.

1. $\angle B = 180^\circ - 110^\circ = 70^\circ$.
2. 대변의 길이가 같으므로 $\overline{CD} = \overline{AB} = 7\,\text{cm}$, $\overline{AD} = \overline{BC} = 4\,\text{cm}$.
3. 둘레는 $2 \times (7 + 4) = 22\,\text{cm}$.

**예제 2 (표준).** 직사각형 $ABCD$의 두 대각선의 교점을 $O$라 하자. $\angle OAB = 35^\circ$일 때 $\angle AOB$와 $\angle OBC$의 크기를 구하시오.

풀이 전략: 직사각형의 대각선은 길이가 같고 서로 이등분하므로 $\overline{OA} = \overline{OB} = \overline{OC} = \overline{OD}$. 이등변삼각형을 찾는다.

1. $\overline{OA} = \overline{OB}$이므로 $\triangle OAB$는 이등변삼각형이고 $\angle OBA = \angle OAB = 35^\circ$.
2. $\angle AOB = 180^\circ - 35^\circ \times 2 = 110^\circ$.
3. $\angle ABC = 90^\circ$이므로 $\angle OBC = 90^\circ - 35^\circ = 55^\circ$.

확인: $\triangle OBC$도 이등변삼각형이므로 $\angle OCB = 55^\circ$, $\angle BOC = 180^\circ - 110^\circ = 70^\circ$이고 $\angle AOB + \angle BOC = 180^\circ$로 일치한다.

**예제 3 (표준).** 평행사변형 $ABCD$에서 $\angle A$의 이등분선이 $\overline{BC}$와 만나는 점을 $E$라 하자. $\overline{AB} = 6$, $\overline{AD} = 10$일 때 $\overline{EC}$의 길이를 구하시오.

풀이 전략: 평행선이 있으면 엇각을 찾는다. 각의 이등분선과 엇각이 겹치면 이등변삼각형이 생긴다.

1. $\overline{AD} \parallel \overline{BC}$이므로 엇각 $\angle DAE = \angle BEA$.
2. $\overline{AE}$는 이등분선이므로 $\angle BAE = \angle DAE$. 따라서 $\angle BAE = \angle BEA$.
3. $\triangle ABE$는 $\overline{BA} = \overline{BE}$인 이등변삼각형이므로 $\overline{BE} = 6$.
4. $\overline{BC} = \overline{AD} = 10$이므로 $\overline{EC} = 10 - 6 = 4$.

**예제 4 (응용).** 길이 $60\,\text{cm}$와 $40\,\text{cm}$인 막대 두 개를 서로의 한가운데에서 직각으로 엇갈리게 묶고, 네 끝을 실로 이어 연을 만들었다. 이 연은 어떤 사각형이며, 넓이는 몇 $\text{cm}^2$인가?

풀이 전략: 막대가 대각선이다. 대각선이 "서로 이등분"하면 평행사변형, 거기에 "수직"이면 마름모.

1. 두 막대가 서로의 한가운데에서 만나므로 대각선이 서로 다른 것을 이등분한다. 따라서 평행사변형이다.
2. 대각선이 수직인 평행사변형이므로 마름모다.
3. 마름모는 대각선에 의해 합동인 직각삼각형 네 개로 나뉜다. 각 직각삼각형의 직각변은 $30\,\text{cm}$, $20\,\text{cm}$이므로 넓이는 $4 \times \dfrac{1}{2} \times 30 \times 20 = 1200\,(\text{cm}^2)$.

확인: 마름모의 넓이 = (한 대각선) $\times$ (다른 대각선) $\div 2 = 60 \times 40 \div 2 = 1200$으로 일치한다.


풀이 전략: 사다리꼴은 보조선으로 평행사변형과 삼각형으로 나눈다.

1. 점 $A$를 지나 $\overline{DC}$에 평행한 직선이 $\overline{BC}$와 만나는 점을 $E$라 하면 $AECD$는 두 쌍의 대변이 평행하므로 평행사변형이다.
2. 따라서 $\overline{EC} = \overline{AD} = 4$, $\overline{AE} = \overline{DC} = 5$.
3. 동위각이므로 $\angle AEB = \angle C = \angle B = 60^\circ$. $\triangle ABE$는 두 각이 $60^\circ$이므로 정삼각형이고 $\overline{BE} = \overline{AB} = 5$.
4. $\overline{BC} = \overline{BE} + \overline{EC} = 5 + 4 = 9$.

확인: $\overline{AE} = 5 = \overline{AB}$로 정삼각형의 세 변이 모두 $5$가 되어 모순이 없다.

### 스스로 확인

1. 평행사변형 $ABCD$에서 $\angle B = 65^\circ$일 때, $\angle A$와 $\angle D$의 크기는?
2. 마름모 $ABCD$의 대각선의 교점을 $O$라 하자. $\angle OAB = 28^\circ$일 때 $\angle ABO$의 크기는?
3. 두 대각선의 길이가 같고, 서로 다른 것을 수직이등분하는 사각형은 무엇인가?

<details>
<summary>정답과 풀이</summary>

1. 이웃한 두 각의 합이 $180^\circ$이므로 $\angle A = 115^\circ$, 대각이 같으므로 $\angle D = \angle B = 65^\circ$.
2. 마름모의 대각선은 수직이므로 $\angle AOB = 90^\circ$. $\triangle ABO$에서 $\angle ABO = 180^\circ - 90^\circ - 28^\circ = 62^\circ$.
3. 서로 이등분하므로 평행사변형, 길이가 같으므로 직사각형, 수직이므로 마름모. 둘 다이므로 정사각형이다.

</details>

## 자주 하는 실수와 오개념

**실수 1. "한 쌍의 대변이 평행하고, 다른 한 쌍의 대변의 길이가 같다"를 평행사변형 조건으로 쓴다.**

- **왜 틀리는가:** 조건 5의 "평행하고 길이가 같다"가 같은 쌍의 변에 대한 조건이라는 점을 놓친다.
- **어떻게 바로잡는가:** 등변사다리꼴이 반례다. $\overline{AD} \parallel \overline{BC}$이고 $\overline{AB} = \overline{DC}$이지만 평행사변형이 아니다. 조건 5를 쓸 때는 "같은 두 변에 평행 표시와 길이 표시를 모두 했는가"를 확인한다.

**실수 2. 직사각형과 마름모의 대각선 성질을 서로 바꿔 쓴다.**

- **왜 틀리는가:** "대각선이 특별하다"는 것만 기억하고 무엇이 특별한지(길이가 같음 / 서로 수직)를 구분하지 못한다.
- **어떻게 바로잡는가:** 가로로 긴 직사각형을 그려 보면 두 대각선은 길이가 같지만 $\times$ 모양으로 비스듬히 만나 수직이 아니다. 납작한 마름모를 그려 보면 두 대각선은 수직이지만 하나는 길고 하나는 짧다. 그림으로 반례를 하나씩 기억한다.

**실수 3. 정사각형은 직사각형(또는 마름모)이 아니라고 생각한다.**

- **왜 틀리는가:** 사각형의 이름을 서로 다른 종류로만 보고 포함 관계로 보지 않는다.
- **어떻게 바로잡는가:** 정의로 판정한다. 직사각형의 정의는 "네 각이 모두 직각"이고 정사각형은 이를 만족하므로 직사각형이다. 같은 이유로 정사각형은 마름모이고, 직사각형·마름모·정사각형은 모두 평행사변형이다. 포함 관계 그림에서 화살표를 거꾸로 거슬러 올라갈 수 있으면 "그 사각형이기도 하다"는 뜻이다.

**실수 4. "대각선이 서로 이등분한다"와 "대각선의 길이가 같다"를 뭉뚱그려 "대각선이 같다"고 쓴다.**

- **왜 틀리는가:** 두 문장을 모두 "같다"로 기억해 평행사변형에서도 $\overline{AC} = \overline{BD}$라고 쓴다.
- **어떻게 바로잡는가:** 이등분은 $\overline{OA} = \overline{OC}$, $\overline{OB} = \overline{OD}$(교점에서 나뉜 조각끼리), 길이가 같음은 $\overline{AC} = \overline{BD}$(대각선 전체끼리)로 식을 구분해 쓴다. 기울어진 평행사변형에서 두 대각선의 길이가 확연히 다름을 그림으로 확인한다.

**실수 5. 이웃한 두 각을 같다고 놓는다.**

- **왜 틀리는가:** "평행사변형은 각이 같다"로만 기억해, 마주 보는 각(대각)과 이웃한 각을 구분하지 않는다.
- **어떻게 바로잡는가:** 같은 것은 **대각**, 이웃한 두 각은 **합이 $180^\circ$**(평행선의 동측내각)다. 예제 1처럼 $\angle A = 110^\circ$이면 $\angle B = 70^\circ$이지 $110^\circ$가 아니다.
