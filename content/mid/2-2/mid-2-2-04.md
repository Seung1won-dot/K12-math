## 핵심 개념

**평행선과 선분의 길이의 비.** $\triangle ABC$에서 $\overline{AB}$, $\overline{AC}$ 위(또는 그 연장선 위)의 점 $D$, $E$에 대해 $\overline{DE} \parallel \overline{BC}$이면 $\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}$이고, $\overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$이다. 거꾸로 이 비가 성립하면 $\overline{DE} \parallel \overline{BC}$이다. 평행선 하나가 삼각형의 두 변을 같은 비율로 자른다고 기억하면 된다.

**삼각형의 중점연결정리.** $\triangle ABC$에서 $\overline{AB}$, $\overline{AC}$의 중점을 각각 $M$, $N$이라 하면 $\overline{MN} \parallel \overline{BC}$이고 $\overline{MN} = \dfrac{1}{2}\overline{BC}$이다. 두 변의 중점을 이은 선분은 나머지 변과 평행하고 길이는 그 절반이다.

**삼각형의 무게중심.** 삼각형의 한 꼭짓점과 마주 보는 변의 중점을 이은 선분을 **중선**이라 한다. 세 중선은 한 점에서 만나며 이 점을 **무게중심**이라 하고 보통 $G$로 쓴다. 무게중심은 각 중선을 꼭짓점 쪽부터 $2 : 1$로 나눈다.

**닮은 도형의 넓이의 비와 부피의 비.** 닮음비가 $m : n$인 두 평면도형의 넓이의 비는 $m^2 : n^2$이다. 닮음비가 $m : n$인 두 입체도형의 겉넓이의 비는 $m^2 : n^2$, 부피의 비는 $m^3 : n^3$이다. 길이가 $k$배가 되면 넓이는 $k^2$배, 부피는 $k^3$배가 된다.

**그림 설명:** $\triangle ABC$에서 $\overline{BC}$의 중점 $D$, $\overline{CA}$의 중점 $E$, $\overline{AB}$의 중점 $F$를 찍고 중선 $\overline{AD}$, $\overline{BE}$, $\overline{CF}$를 긋는다. 세 중선의 교점 $G$를 표시하고, $\overline{AG}$ 옆에 "2", $\overline{GD}$ 옆에 "1"을 적는다.

## 공식·정리

**평행선과 선분의 길이의 비** ($\triangle ABC$에서 $D \in \overline{AB}$, $E \in \overline{AC}$, $\overline{DE} \parallel \overline{BC}$일 때)

$$\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}, \qquad \overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$$

- 조건: $\overline{DE} \parallel \overline{BC}$를 먼저 확인해야 한다. $\overline{AD} : \overline{DB} = \overline{DE} : \overline{BC}$는 **성립하지 않는다**.
- 세 평행선이 두 직선과 만날 때 잘린 선분의 길이의 비도 같다: $l \parallel m \parallel n$이면 $a : b = a' : b'$.

**삼각형의 각의 이등분선** ($\triangle ABC$에서 $\angle A$의 이등분선이 $\overline{BC}$와 만나는 점을 $D$라 할 때)

$$\overline{AB} : \overline{AC} = \overline{BD} : \overline{CD}$$

**중점연결정리** ($\overline{AM} = \overline{MB}$, $\overline{AN} = \overline{NC}$일 때)

$$\overline{MN} \parallel \overline{BC}, \qquad \overline{MN} = \dfrac{1}{2}\overline{BC}$$

- 역: $\overline{AM} = \overline{MB}$이고 $\overline{MN} \parallel \overline{BC}$이면 $\overline{AN} = \overline{NC}$.

**무게중심** ($\triangle ABC$의 무게중심 $G$, 중선 $\overline{AD}$, $\overline{BE}$, $\overline{CF}$)

- $\overline{AG} : \overline{GD} = \overline{BG} : \overline{GE} = \overline{CG} : \overline{GF} = 2 : 1$.
- $\triangle GAB = \triangle GBC = \triangle GCA = \dfrac{1}{3}\triangle ABC$. 세 중선은 삼각형을 넓이가 같은 여섯 조각으로 나눈다(각각 $\dfrac{1}{6}\triangle ABC$).

**닮은 도형의 넓이·겉넓이·부피** (닮음비 $m : n$)

- 넓이의 비 $= m^2 : n^2$, 겉넓이의 비 $= m^2 : n^2$, 부피의 비 $= m^3 : n^3$. (조건: 두 도형이 반드시 닮음이어야 한다. 둘레의 길이의 비는 $m : n$ 그대로.)

## 왜 성립하는가

**평행선과 선분의 길이의 비.** $\overline{DE} \parallel \overline{BC}$이면 동위각으로 $\angle ADE = \angle ABC$, $\angle AED = \angle ACB$이므로 $\triangle ADE \sim \triangle ABC$ (AA 닮음)이다. 따라서 $\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}$. 또 $\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC}$에서 $\overline{AD} \cdot \overline{AC} = \overline{AE} \cdot \overline{AB}$이고, $\overline{AB} = \overline{AD} + \overline{DB}$, $\overline{AC} = \overline{AE} + \overline{EC}$를 대입해 정리하면 $\overline{AD} \cdot \overline{EC} = \overline{AE} \cdot \overline{DB}$, 즉 $\overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$를 얻는다.

**중점연결정리.** $\overline{AM} : \overline{AB} = \overline{AN} : \overline{AC} = 1 : 2$이고 $\angle A$가 공통이므로 $\triangle AMN \sim \triangle ABC$ (SAS 닮음)이다. 따라서 $\overline{MN} : \overline{BC} = 1 : 2$이고, 대응각 $\angle AMN = \angle ABC$가 동위각으로 같으므로 $\overline{MN} \parallel \overline{BC}$이다.

**무게중심이 중선을 $2 : 1$로 나누는 이유.** $\overline{AC}$, $\overline{AB}$의 중점을 각각 $E$, $F$라 하고 중선 $\overline{BE}$와 $\overline{CF}$의 교점을 $G$라 하자. 중점연결정리에서 $\overline{FE} \parallel \overline{BC}$, $\overline{FE} = \dfrac{1}{2}\overline{BC}$이다. $\triangle GFE$와 $\triangle GCB$는 엇각으로 두 쌍의 각이 같아 AA 닮음이고 닮음비는 $\overline{FE} : \overline{CB} = 1 : 2$이다. 따라서

$$\overline{GE} : \overline{GB} = \overline{GF} : \overline{GC} = 1 : 2, \quad \text{즉 } \overline{BG} : \overline{GE} = \overline{CG} : \overline{GF} = 2 : 1.$$

나머지 중선 $\overline{AD}$와 $\overline{BE}$의 교점 $G'$에 대해서도 똑같이 $\overline{BG'} : \overline{G'E} = 2 : 1$이 되므로 $G'$과 $G$는 $\overline{BE}$ 위의 같은 점이다. 따라서 세 중선은 한 점 $G$에서 만난다.

**넓이의 비가 $m^2 : n^2$인 이유.** 닮음비가 $m : n$이면 밑변의 길이의 비도 $m : n$, 높이의 비도 $m : n$이다. 삼각형의 넓이는 $\dfrac{1}{2} \times (\text{밑변}) \times (\text{높이})$이므로 넓이의 비는 $m \times m : n \times n = m^2 : n^2$이다. 다각형은 삼각형으로 잘라 더하면 되므로 마찬가지다. 입체도형의 부피는 가로·세로·높이 세 방향이 모두 $m : n$이므로 $m^3 : n^3$이다.

## 대표 예제

**예제 1 (교과서 수준).** $\triangle ABC$에서 $\overline{AB}$ 위의 점 $D$, $\overline{AC}$ 위의 점 $E$에 대해 $\overline{DE} \parallel \overline{BC}$이다. $\overline{AD} = 6$, $\overline{DB} = 3$, $\overline{AE} = 4$, $\overline{BC} = 12$일 때 $\overline{EC}$와 $\overline{DE}$의 길이를 구하시오.

$\overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$이므로 $6 : 3 = 4 : \overline{EC}$, $6\,\overline{EC} = 12$, $\overline{EC} = 2$.

$\overline{AD} : \overline{AB} = \overline{DE} : \overline{BC}$이므로 $6 : 9 = \overline{DE} : 12$, $9\,\overline{DE} = 72$, $\overline{DE} = 8$.

확인: $\overline{AD} : \overline{AB} = 6 : 9 = 2 : 3$, $\overline{AE} : \overline{AC} = 4 : 6 = 2 : 3$, $\overline{DE} : \overline{BC} = 8 : 12 = 2 : 3$으로 모두 일치한다.

**예제 2 (교과서 수준).** $\triangle ABC$의 무게중심을 $G$, $\overline{BC}$의 중점을 $D$라 하자. $\overline{AD} = 12\,\text{cm}$이고 $\triangle ABC$의 넓이가 $36\,\text{cm}^2$일 때, $\overline{AG}$의 길이와 $\triangle GBD$의 넓이를 구하시오.

$\overline{AG} : \overline{GD} = 2 : 1$이므로 $\overline{AG} = 12 \times \dfrac{2}{3} = 8\,\text{cm}$, $\overline{GD} = 4\,\text{cm}$.

세 중선은 삼각형을 넓이가 같은 여섯 조각으로 나누므로 $\triangle GBD = 36 \times \dfrac{1}{6} = 6\,\text{cm}^2$.

확인: $\triangle GBC = \dfrac{1}{3} \times 36 = 12\,\text{cm}^2$이고 $D$가 $\overline{BC}$의 중점이므로 $\triangle GBD$는 그 절반인 $6\,\text{cm}^2$로 일치한다.

**예제 3 (심화).** (1) 닮음비가 $2 : 3$인 두 원기둥 $P$, $Q$가 있다. $P$의 겉넓이가 $40\,\text{cm}^2$, 부피가 $24\,\text{cm}^3$일 때 $Q$의 겉넓이와 부피를 구하시오. (2) 원뿔을 밑면에 평행한 평면으로 높이를 $1 : 2$로 나누도록(꼭짓점 쪽이 $1$) 잘랐다. 잘라 낸 작은 원뿔과 남은 원뿔대의 부피의 비를 구하시오.

(1) 겉넓이의 비는 $2^2 : 3^2 = 4 : 9$이므로 $40 : x = 4 : 9$, $4x = 360$, $x = 90\,\text{cm}^2$. 부피의 비는 $2^3 : 3^3 = 8 : 27$이므로 $24 : y = 8 : 27$, $8y = 648$, $y = 81\,\text{cm}^3$.

확인: $40 \times \dfrac{9}{4} = 90$, $24 \times \dfrac{27}{8} = 3 \times 27 = 81$로 일치한다.

(2) 작은 원뿔과 원래 원뿔은 닮음이고 높이의 비가 $1 : 3$이므로 닮음비는 $1 : 3$, 부피의 비는 $1^3 : 3^3 = 1 : 27$. 원뿔대의 부피는 $27 - 1 = 26$이므로 (작은 원뿔) : (원뿔대) $= 1 : 26$.

확인: 작은 원뿔의 부피를 $1$이라 하면 전체는 $27$, 원뿔대는 $27 - 1 = 26$으로 두 조각의 합이 전체와 같다.

## 자주 하는 실수와 오개념

**실수 1. 닮음비가 $2 : 3$이면 넓이의 비도 $2 : 3$이라고 쓴다.**

- **왜 틀리는가:** 길이의 비가 넓이와 부피에도 그대로 옮겨 간다고 생각한다.
- **어떻게 바로잡는가:** 한 변이 $2$인 정사각형과 $3$인 정사각형을 그리면 넓이는 $4$와 $9$다. "길이는 한 번, 넓이는 두 번, 부피는 세 번 곱한다"를 식 $m : n \to m^2 : n^2 \to m^3 : n^3$으로 적어 두고 문제마다 무엇을 묻는지(길이·넓이·부피) 먼저 확인한다.

**실수 2. 무게중심의 $2 : 1$ 방향을 거꾸로 쓴다.**

- **왜 틀리는가:** $\overline{AG} : \overline{GD} = 2 : 1$에서 어느 쪽이 $2$인지 기억하지 못하고, 중점 쪽을 길게 잡는다.
- **어떻게 바로잡는가:** 무게중심은 꼭짓점보다 변에 더 가깝다. 즉 꼭짓점에서 무게중심까지가 긴 쪽(2), 무게중심에서 변의 중점까지가 짧은 쪽(1)이다. 중선 길이가 $12$이면 $8$과 $4$로 나뉘고, $8$이 꼭짓점 쪽임을 그림에 표시한다.

**실수 3. $\overline{AD} : \overline{DB} = \overline{DE} : \overline{BC}$라고 쓴다.**

- **왜 틀리는가:** 비례식의 네 항을 "위쪽 조각 : 아래쪽 조각"으로 아무렇게나 짝지어, 변 전체($\overline{AB}$)와 비교해야 할 $\overline{DE} : \overline{BC}$를 조각끼리의 비와 섞는다.
- **어떻게 바로잡는가:** $\overline{DE} : \overline{BC}$는 작은 삼각형과 큰 삼각형의 닮음비이므로 반드시 "꼭짓점에서 잰 길이" $\overline{AD} : \overline{AB}$와 짝짓는다. 조각끼리의 비 $\overline{AD} : \overline{DB}$는 $\overline{AE} : \overline{EC}$하고만 짝지을 수 있다.

**실수 4. 평행 조건을 확인하지 않고 비례식을 세운다.**

- **왜 틀리는가:** 삼각형 안에 선분이 그어져 있기만 하면 평행선의 성질을 쓴다.
- **어떻게 바로잡는가:** 평행 표시(화살표)나 "$\parallel$" 조건이 문제에 있는지 먼저 찾는다. 없다면 중점연결정리의 조건(두 중점)이나 각의 이등분선 조건처럼 다른 근거가 있어야 비례식을 쓸 수 있다.

## 앞뒤 학년 연계

이 단원의 정리들은 모두 앞 단원의 삼각형 닮음 조건(특히 AA, SAS)으로 증명되며, 평행사변형의 성질도 함께 쓰인다. 3학년의 삼각비에서는 닮은 직각삼각형의 변의 비가 일정하다는 사실을 각의 크기에 따른 값으로 정리하고, 넓이·부피의 비는 고등학교에서 도형의 확대·축소나 닮음 변환을 다룰 때 다시 나온다.
