## 핵심 개념

**다항식의 곱셈**은 분배법칙으로 괄호를 푸는 것이다. $(a+b)(c+d)$는 $a$와 $b$를 각각 $c$, $d$에 곱해 $ac + ad + bc + bd$가 된다. 이렇게 괄호를 풀어 하나의 다항식으로 쓰는 것을 **전개**라고 한다.

자주 나오는 모양의 전개 결과를 외워 두면 매번 분배법칙을 쓰지 않아도 된다. 이것이 **곱셈 공식**이다. 예를 들어 $(a+b)^2$은 $a^2 + 2ab + b^2$으로, 가운데 $2ab$가 꼭 생긴다.

**인수분해**는 전개의 반대다. 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것이며, 이때 곱해지는 각 식을 **인수**라고 한다. $x^2 + 5x + 6 = (x+2)(x+3)$에서 $x+2$와 $x+3$이 인수다.

$a^2 + 2ab + b^2 = (a+b)^2$처럼 다항식의 제곱으로 인수분해되는 식을 **완전제곱식**이라고 한다. 이차방정식과 이차함수에서 계속 쓰이므로 "어떤 식이 완전제곱식이 되는 조건"까지 알아 둬야 한다.

**그림 설명:** 한 변의 길이가 $a + b$인 정사각형을 그리고, 가로·세로를 각각 $a$와 $b$로 나누는 선을 긋는다. 왼쪽 위는 한 변 $a$인 정사각형(넓이 $a^2$), 오른쪽 아래는 한 변 $b$인 정사각형(넓이 $b^2$), 나머지 두 직사각형은 각각 넓이 $ab$다. 네 조각을 더하면 $a^2 + 2ab + b^2$이다.

## 공식·정리

**곱셈 공식** (모든 수 $a$, $b$, $x$에 대해 항상 성립)

$$
\begin{aligned}
(a+b)^2 &= a^2 + 2ab + b^2 \\
(a-b)^2 &= a^2 - 2ab + b^2 \\
(a+b)(a-b) &= a^2 - b^2 \\
(x+a)(x+b) &= x^2 + (a+b)x + ab \\
(ax+b)(cx+d) &= acx^2 + (ad+bc)x + bd
\end{aligned}
$$

**인수분해 공식** (곱셈 공식을 오른쪽에서 왼쪽으로 읽은 것)

- 공통인수 묶기: $ma + mb = m(a+b)$. 항상 **가장 먼저** 확인한다.
- $a^2 + 2ab + b^2 = (a+b)^2$, $\quad a^2 - 2ab + b^2 = (a-b)^2$
- $a^2 - b^2 = (a+b)(a-b)$
- $x^2 + (a+b)x + ab = (x+a)(x+b)$: 곱해서 상수항, 더해서 $x$의 계수가 되는 두 수를 찾는다.
- $acx^2 + (ad+bc)x + bd = (ax+b)(cx+d)$

**완전제곱식이 되는 조건**

- $x^2 + ax + b$가 완전제곱식이려면 $b = \left(\dfrac{a}{2}\right)^2$이어야 한다. (상수항은 "$x$의 계수의 절반의 제곱")
- $x^2 + ax + b^2$ ($b > 0$)이 완전제곱식이려면 $a = \pm 2b$이어야 한다.

## 왜 성립하는가

곱셈 공식은 모두 분배법칙에서 나온다. $(a+b)^2 = (a+b)(a+b)$를 전개하면

$$
(a+b)(a+b) = a \cdot a + a \cdot b + b \cdot a + b \cdot b = a^2 + ab + ab + b^2 = a^2 + 2ab + b^2
$$

이다. 같은 항 $ab$가 두 번 나오기 때문에 $2ab$가 생긴다. 핵심 개념의 넓이 그림도 같은 사실을 보여 준다. 큰 정사각형의 넓이 $(a+b)^2$은 조각 네 개의 넓이 합 $a^2 + ab + ab + b^2$과 같다.

$(a-b)^2$은 $b$ 자리에 $-b$를 넣으면 된다. $(-b)^2 = b^2$이므로 마지막 항은 그대로이고, 가운데 항만 $2a(-b) = -2ab$로 부호가 바뀐다.

합차 공식은 전개 중에 가운데 항이 사라진다.

$$
(a+b)(a-b) = a^2 - ab + ab - b^2 = a^2 - b^2
$$

$(x+a)(x+b)$를 전개하면 $x^2 + bx + ax + ab = x^2 + (a+b)x + ab$이다. 그래서 인수분해할 때는 "더해서 $x$의 계수, 곱해서 상수항"이 되는 두 수를 찾는 것이다.

인수분해가 맞는지는 **다시 전개해서** 원래 식이 나오는지로 확인한다. 전개와 인수분해는 서로 반대 과정이므로 이 확인은 항상 가능하다.

## 대표 예제

**예제 1 (교과서 수준).** 다음을 전개하시오. $(2x+3)^2$, $(x+5)(x-5)$, $(x+2)(x-7)$

$(2x+3)^2 = (2x)^2 + 2 \cdot 2x \cdot 3 + 3^2 = 4x^2 + 12x + 9$.

$(x+5)(x-5) = x^2 - 25$.

$(x+2)(x-7)$: 더하면 $2 + (-7) = -5$, 곱하면 $2 \times (-7) = -14$이므로 $x^2 - 5x - 14$. 분배법칙으로 확인하면 $x^2 - 7x + 2x - 14 = x^2 - 5x - 14$로 같다.

**예제 2 (교과서 수준).** 다음을 인수분해하시오. $x^2 - 6x + 9$, $3x^2 - 12$, $x^2 + x - 12$

$x^2 - 6x + 9$: 상수항 $9 = \left(\dfrac{-6}{2}\right)^2$이므로 완전제곱식이다. $(x-3)^2$.

$3x^2 - 12$: 공통인수 $3$을 먼저 묶으면 $3(x^2 - 4)$, 괄호 안은 합차 공식으로 $3(x+2)(x-2)$.

$x^2 + x - 12$: 곱해서 $-12$, 더해서 $1$인 두 수는 $4$와 $-3$이다. $(x+4)(x-3)$. 전개해서 확인: $x^2 - 3x + 4x - 12 = x^2 + x - 12$.

**예제 3 (심화).** (1) $x^2 + ax + 16$이 완전제곱식이 되도록 하는 양수 $a$를 구하시오. (2) $2x^2 + 7x + 3$을 인수분해하시오. (3) 곱셈 공식을 이용해 $101^2 - 99^2$을 계산하시오.

(1) 상수항이 $x$의 계수의 절반의 제곱이어야 하므로 $\left(\dfrac{a}{2}\right)^2 = 16$, $\dfrac{a}{2} = \pm 4$. $a > 0$이므로 $a = 8$. 확인: $x^2 + 8x + 16 = (x+4)^2$.

(2) $(ax+b)(cx+d)$ 꼴에서 $ac = 2$, $bd = 3$이고 $ad + bc = 7$이어야 한다. $(2x+1)(x+3)$을 전개하면 $2x^2 + 6x + x + 3 = 2x^2 + 7x + 3$이므로 맞다. 답 $(2x+1)(x+3)$.

(3) $101^2 - 99^2 = (101+99)(101-99) = 200 \times 2 = 400$. 직접 계산해도 $10201 - 9801 = 400$이다.

## 자주 하는 실수와 오개념

**실수 1. $(a+b)^2 = a^2 + b^2$이라고 쓴다.**
왜 틀리는가: 제곱을 각 항에 따로 나눠 줄 수 있다고 착각한다. 곱셈 $(ab)^2 = a^2 b^2$은 되지만 덧셈에는 안 된다.
어떻게 바로잡는가: $a = 1$, $b = 1$을 넣어 보면 $(1+1)^2 = 4$인데 $1^2 + 1^2 = 2$다. 넓이 그림에서 직사각형 두 개($2ab$)가 빠졌음을 보여 주고, "제곱하면 가운데 항이 꼭 생긴다"고 기억하게 한다.

**실수 2. $(a-b)^2$의 마지막 항을 $-b^2$으로 쓴다.**
왜 틀리는가: 빼기가 있으니 뒤에도 빼기를 붙인다고 생각한다. 실제로 부호가 바뀌는 것은 가운데 항뿐이다.
어떻게 바로잡는가: $(a-b)^2 = (a + (-b))^2$으로 보고 $(-b)^2 = +b^2$임을 직접 계산한다. $(3-1)^2 = 4$를 $9 - 6 + 1 = 4$로 확인한다.

**실수 3. 공통인수를 묶지 않거나 끝까지 인수분해하지 않는다.**
왜 틀리는가: $3x^2 - 12$에서 바로 공식을 찾으려다 못 찾거나, $x^4 - 16 = (x^2+4)(x^2-4)$에서 멈춘다.
어떻게 바로잡는가: 순서를 고정한다. ① 공통인수 묶기 → ② 공식 적용 → ③ 괄호 안이 더 인수분해되는지 다시 보기. $x^2 - 4$는 한 번 더 $(x+2)(x-2)$로 쪼개진다.

**실수 4. $x^2 + (a+b)x + ab$에서 두 수의 부호를 거꾸로 고른다.**
왜 틀리는가: $x^2 - 5x - 14$에서 곱이 $-14$인 것만 보고 $7$과 $-2$를 골라 $(x+7)(x-2)$라고 쓴다. 이러면 더한 값이 $+5$가 되어 부호가 반대다.
어떻게 바로잡는가: 상수항이 음수면 두 수의 부호가 다르고, 절댓값이 큰 쪽이 $x$의 계수의 부호를 따른다. 고른 뒤에는 반드시 전개해서 가운데 항의 부호를 확인한다.
