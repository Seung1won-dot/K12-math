# 디자인·움직임 규칙

토큰(색·글자 크기·간격·반경)은 `src/styles/global.css` 맨 위에 있다. 검정 바탕, 흰 글자 3단계(100/72/56%), 오렌지 하나, 그림자 대신 1px 선. 이 문서는 그 위에 얹는 조판과 움직임 규칙만 적는다.

## 조판

- 한국어는 `word-break: keep-all`로 어절 단위로만 줄을 바꾼다. 제목은 `text-wrap: balance`, 본문 문단은 `text-wrap: pretty`.
- 단원 본문은 줄 간격 1.8, 읽기 폭 720px. 1120px 이상 화면에서는 오른쪽에 고정 목차(현재 절 표시)를 두고, 그보다 좁으면 본문 위 칩 목차를 쓴다.
- 수식(KaTeX)은 본문보다 1.06배, 줄 수식은 1.12배. 긴 줄 수식은 그 블록만 가로 스크롤.

## 움직임

읽는 사이트다. 움직임은 **홈 첫 화면, 카드, 내비게이션 피드백**에만 쓴다.

| 어디 | 무엇 | 도구 |
| --- | --- | --- |
| 홈 히어로 | 제목 글자가 한 글자씩 떠오름, 뒤 수학 기호 판이 가운데서 물결처럼 퍼짐 | Anime.js v4 (`animate`, `stagger` grid) |
| 홈 카드·차트·숫자 | 화면에 들어올 때 한 번 떠오름, 카드 올림/누름 스프링, 막대 자람, 숫자 세기 | Motion vanilla (`animate`, `inView`, `hover`, `press`, `stagger`) |
| 학교급 페이지 | 학기 섹션의 단원 줄이 차례로 떠오름 | Motion (`inView`, `stagger`) |
| 페이지 이동 | 본문 짧은 교차 전환, 메뉴 밑줄이 다음 메뉴로 미끄러짐 | CSS cross-document View Transitions (JS 없음) |
| 단원 페이지 | 읽기 진행 막대, 옆 목차 현재 위치. **본문·수식·그림은 움직이지 않는다** | CSS 스크롤 연동 + 작은 스크립트(라이브러리 없음) |
| 버튼·링크 | 누름 0.95~0.98배, 화살표 3px 밀림 | CSS transition |

규칙

1. **줄이기 설정 존중.** `prefers-reduced-motion: reduce`면 전환·애니메이션을 모두 끈다(CSS에서 0ms, 스크립트는 `motionOk()`가 false라 아무것도 하지 않는다, View Transition도 끈다).
2. **JS 없이도 다 보인다.** 숨겼다 보여 주기는 `<html class="motion-ok">`(머리 인라인 스크립트가 붙임)일 때 `data-reveal` 요소에만. 스크립트가 넘겨받으면 `data-reveal="on"`으로 바꾸고, 못 넘겨받으면 3초 뒤 CSS가 저절로 보이게 한다.
3. **필요한 페이지에서만 싣는다.** Anime.js는 홈에서만, Motion은 홈과 학교급 페이지에서만 import한다(`src/scripts/motion.ts`). 공통 레이아웃에는 애니메이션 라이브러리를 넣지 않는다.
4. **짧게.** 등장 0.5초 안팎, 한 번만. 반복·자동 재생 애니메이션은 쓰지 않는다. Motion+(유료)는 쓰지 않는다.
5. 차트는 데이터가 있을 때만(홈의 학년별 단원 수). React가 없는 사이트라 Bklit UI 대신 HTML 막대 + Motion으로 그렸다.
