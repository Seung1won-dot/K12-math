# 검토 대기 목록 — 초등 콘텐츠 초안

초안을 작성한 뒤 작성자(에이전트)가 "사람이 꼭 확인해야 할 지점"으로 남긴 항목이다.
각 단원을 `reviewed`로 올리기 전에 해당 항목을 확인하고, 처리한 항목은 줄 앞에 `[x]`를 표시한다.
교과서 범위 판단은 **2022 개정 교육과정 성취기준과 2024~2026년 적용 국정 교과서 목차**를 기준으로 한다.

## 공통

- [ ] **단원명·순서 대조.** 초등 71단원의 이름과 순서는 국정 교과서 구성을 기준으로 잡았다. 2022 개정 교과서(1~2학년 2024, 3~4학년 2025, 5~6학년 2026 적용)와 다를 수 있으니 목차와 대조한다. 단원 ID는 바꾸지 말고 `title`과 `data/units.json`만 고친다.
- [ ] **분량.** 여러 단원이 기준(2,000~3,000자)보다 길다(마크업 포함 3,400~5,400자). 줄일 때는 "왜 성립하는가"의 마지막 문단이나 심화 예제의 둘째 물음부터 뺀다.
- [ ] **자작 수치.** 그래프·통계 단원(2-2-05, 3-2-06, 4-1-05, 4-2-05, 6-1-05 등)의 자료는 모두 가상 수치다. 그림을 넣을 때 "예시 자료"로 표시한다.
- [ ] **앞뒤 학년 연계 문단.** 후속 단원 설명이 `next` ID의 실제 단원 제목과 맞는지 대조한다(작성 시 제목을 직접 읽지 않은 경우가 있음).
- [ ] **1차분 미보고.** 1-1 전체, 2-1 01~03, 4-1 전체, 5-1-01, 6-1 01~03 은 작성 에이전트가 중단돼 확인 지점 보고가 없다. 아래 기준으로 직접 점검한다: 예제 답 재계산, 교과 범위, 오개념 쌍.
  - 2026-11-22 1차 점검(에이전트): 18단원의 예제 답·그림 수치·연계 단원 제목을 다시 계산해 대조했다. 계산 오류는 없었고 8단원의 서술 12곳을 고쳤다(1-1-02, 1-1-03, 1-1-04, 2-1-02, 4-1-01, 4-1-02, 4-1-03, 6-1-03). **교과 범위는 아직 사람이 확인하지 않았다.**
